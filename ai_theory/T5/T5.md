## 2. distribution、random variable 与 sample

`distribution` 是概率规则，不是一串已经生成的数据。

`random variable` 把 random outcome 映射成 value。

`sample` 是按 distribution 进行一次随机试验后得到的 realization。

以 Bernoulli random variable $X$ 为例：

$$
P(X=1)=p,qquad P(X=0)=1-p
$$

$p=0.7$ 描述 distribution；某一次得到 $1$ 是 sample；一万个 0/1 values 是一组 samples。

## 3. NumPy 的 random Generator

```python
import numpy as np

rng = np.random.default_rng(seed=2026)
uniform_values = rng.random(5)
```

`default_rng(seed)` 创建 `Generator`。它内部持有 pseudo-random state；相同实现、相同 seed 和相同调用顺序通常产生同一序列。

`rng.random(size)` 产生 $[0,1)$ 上的 uniform samples。Bernoulli sampling 可以写成：

```python
bernoulli_samples = (rng.random(sample_count) < probability).astype(np.int64)
```

每个 uniform sample 小于 $p$ 的概率就是 $p$。

官方查证：[NumPy Random Generator](https://numpy.org/doc/stable/reference/random/generator.html)。

## 4. theoretical statistics 与 empirical statistics

Bernoulli distribution：

$$
\mathbb E[X]=p,qquad
\operatorname{Var}(X)=p(1-p)
$$

code 中：

```python
empirical_mean = np.mean(samples)
empirical_variance = np.var(samples)
```

`empirical` 表示由观察 samples 计算得到。它们通常接近 theoretical values，但有限 samples 下不要求精确相等。

```text
theoretical expectation：distribution 定义的量
sample mean：当前这批 samples 的统计量
```

增加 sample count 往往使 sample mean 更稳定地接近 expectation，但 seed 固定并不能把随机误差变成零。

## 5. variance 在 code 中说明什么

variance 衡量 random variable 围绕 mean 的波动：

$$
\operatorname{Var}(X)
=
\mathbb E[(X-\mathbb E[X])^2]
$$

两组 samples mean 接近，不代表 distribution 相同；variance 可能不同。模型 sampling 中，不能只报告 average 而忽略 variability。

NumPy `np.var` 默认除以 $N$，对应 population variance 形式。学校统计学中若讨论无偏 sample variance，常使用 $N-1$；不要混为同一个 estimator。

## 6. conditional probability 的方向

$$
P(A\mid B)=\frac{P(A\cap B)}{P(B)}
$$

`A | B` 读作“在 $B$ 已发生条件下 $A$ 的概率”。它一般不等于 $P(B\mid A)$。

Bayes rule：

$$
P(A\mid B)
=
\frac{P(B\mid A)P(A)}{P(B)}
$$

T5 只抓对象方向。后续模型中的 $P(\text{next token}\mid\text{context})$ 表示 context 已知时 next-token distribution，不是反过来。

## 7. independence 不等于 mutually exclusive

independent：

$$
P(A\cap B)=P(A)P(B)
$$

mutually exclusive 表示 $A\cap B=\varnothing$。若两个非零概率 events mutually exclusive，它们通常不 independent，因为一个发生会排除另一个。

这不是术语小差异，而是 joint behavior 完全不同。

## 8. PMF 与 PDF

discrete random variable 使用 PMF：

$$
p_X(x)=P(X=x)
$$

PMF values 可以直接相加成 probability。

continuous random variable 使用 PDF。单点 density 不是该点 probability：

$$
P(a\le X\le b)=\int_a^b f_X(x)\,dx
$$

LLM token sampling 是 finite categories 上的 discrete distribution，因此使用每个 token 的 probability mass，不是 continuous PDF。

## 9. categorical distribution 与 index

设 categories：

```python
categories = np.array([10, 20, 30])
probabilities = np.array([0.2, 0.3, 0.5])
```

要求：

$$
p_i\ge0,qquad \sum_i p_i=1
$$

sampling：

```python
samples = rng.choice(
    categories,
    size=sample_count,
    replace=True,
    p=probabilities,
)
```

`replace=True` 表示一次抽样不会从 distribution 中永久移除 category。

若 model output 的 categories 是 class/token indices，可以统计：

```python
indices = rng.choice(3, size=sample_count, p=probabilities)
counts = np.bincount(indices, minlength=3)
frequencies = counts / sample_count
```

`np.bincount` 的 input 应是 non-negative integer indices。category value 若是 `10,20,30`，不能直接把 counts array 的 index 当成它们的业务含义。

## 10. prediction 与 sampling 不是一回事

给定 probabilities：

```text
[0.2, 0.3, 0.5]
```

argmax prediction 总选择 index 2。categorical sampling 则让每次输出按 distribution 随机产生，长期 frequency 接近 probabilities。

```text
argmax：deterministic decision
sampling：stochastic draw
```

LLM decoding 中 greedy、temperature、top-k、top-p 会在 T19 专门处理。T5 只建立“distribution 不等于一个确定答案”。

## 11. seed 能保证什么

seed 的作用是让实验更容易复现和调试：

```python
rng_a = np.random.default_rng(2026)
rng_b = np.random.default_rng(2026)

np.testing.assert_array_equal(
    rng_a.random(10),
    rng_b.random(10),
)
```

但 seed 不表示：

```text
随机模型变成 deterministic theory
不同 library/version/device 必然 bitwise identical
并发调用顺序变化后仍得到同一 stream
实验结果可以由一个 seed 推广
```

安全或密码学随机数也不应使用 NumPy PRNG。

## 13. 与 AI Infra 的连接

model forward 常产生 logits，softmax 把 logits 映射成 categorical probabilities，sampler 再从 distribution 产生 token index：

```text
logits
-> probabilities
-> sampling policy
-> selected token index
```

distribution、sample 和 selected index 是三类不同对象。把它们混成“模型输出一个概率”会让后续 API、测试和性能边界全部模糊。
