## 0. 今天只回答一个问题

假设模型面对三个 token，给出：

```text
[0.2, 0.3, 0.5]
```

这三个数是什么意思？

它们不是“模型已经选中了第三个 token”，也不是“三个 token 各自会出现多少次”的观测结果。它们描述的是一条 probability distribution（概率分布）：如果不断在相同条件下抽取，下标 `0/1/2` 应分别以大约 `20%/30%/50%` 的频率出现。

今天要把这条链讲清：

```text
distribution：抽取规则
-> random variable：把随机结果表示成数值
-> sample：一次真实抽取
-> empirical statistics：有限 samples 的统计结果
-> prediction / sampling：两种不同的使用策略
```

这就是 T5 的终点。学校概率论负责完整定义、证明和习题；这里负责把你已经学过的概率对象接到模型输出与 Python code 上。

## 1. 先看一次抽取到底发生了什么

设 categories 是：

```text
0：red
1：green
2：blue
```

对应 probabilities：

$$
\mathbf p=
\begin{bmatrix}
0.2 & 0.3 & 0.5
\end{bmatrix}
$$

程序按照 $\mathbf p$ 抽一次，可能得到 `2`。这里：

- $\mathbf p$ 是 distribution（分布规则）；
- `0/1/2` 是可能 outcomes（结果）；
- 把 outcome 表成 integer index 的对象叫 random variable（随机变量）；
- 本次真正得到的 `2` 是一个 sample（样本/一次实现）。

再抽一次仍可能得到 `2`，也可能得到 `0`。概率最高不等于每次必然发生。

如果连续抽取十万次并统计频率，结果通常会靠近 `[0.2, 0.3, 0.5]`，但有限样本不会精确复制理论概率。

## 3. Expectation：如果重复很多次，平均结果指向哪里

对离散 random variable $X$，expectation（期望）是：

$$
\mathbb E[X]
=
\sum_x xP(X=x)
$$

考虑 Bernoulli random variable（伯努利随机变量）：

$$
P(X=1)=p,
\qquad
P(X=0)=1-p
$$

它的期望为：

$$
\mathbb E[X]
=
1\cdot p+0\cdot(1-p)
=p
$$

因此当 $p=0.7$ 时，重复抽取大量 `0/1` 后，sample mean 通常会靠近 `0.7`。

注意 expectation 不是“下一次一定出现的值”。它描述 distribution 的加权中心。对骰子，期望可以是 `3.5`，但单次 sample 永远不会掷出 `3.5`。

## 4. Variance：平均值相同，波动仍然可能不同

variance（方差）衡量 random variable 围绕 expectation 的波动：

$$
\operatorname{Var}(X)
=
\mathbb E\left[(X-\mathbb E[X])^2\right]
$$

Bernoulli 的方差是：

$$
\operatorname{Var}(X)=p(1-p)
$$

当 $p$ 接近 `0` 或 `1` 时，结果几乎固定，variance 很小；当 $p=0.5$ 时，两种结果最不确定，variance 最大。

两组输出即使 mean 相同，也可能有完全不同的 variability（波动程度）。所以在 sampling 或 benchmark 中只报告平均值，往往不够。

NumPy 中：

```python
empirical_mean = np.mean(samples)
empirical_variance = np.var(samples)
```

这里 empirical（经验的）表示“由当前有限 samples 算出来”。`np.var` 默认除以 $N$；学校统计学中的无偏 sample variance 常除以 $N-1$。它们是不同 estimator（估计量），不要只看都叫 variance 就混用。

## 5. 理论量与有限实验为什么不会完全相等

假设用 $p=0.7$ 做三组实验：

```text
20 samples
1,000 samples
100,000 samples
```

每组的 mean 都可能偏离 `0.7`。sample count 增大后，误差通常更稳定地缩小，但不保证每一次都单调下降：

```text
20 个样本误差 0.03
1,000 个样本误差 0.01
100,000 个样本误差 0.002
```

这是可能的轨迹，不是固定答案。正确 evidence 应观察整体趋势与合理 tolerance，而不是断言“后一次误差必须严格小于前一次”。

这也解释了为什么统计实验不能像纯函数那样只写一个 exact-value assertion。

## 6. 条件概率：先说清楚“已知什么”

假设某项服务请求可能失败：

```text
A：本次请求超时
B：当前机器 CPU utilization > 95%
```

$P(A\mid B)$ 表示已经知道高 CPU，继续问请求超时的概率：

$$
P(A\mid B)
=
\frac{P(A\cap B)}{P(B)}
$$

$P(B\mid A)$ 则是已经观察到超时，再问机器高 CPU 的概率。两者条件相反，通常不相等。

Bayes rule（贝叶斯公式）把这两个方向联系起来：

$$
P(A\mid B)
=
\frac{P(B\mid A)P(A)}{P(B)}
$$

以后写：

$$
P(\text{next token}\mid\text{context})
$$

意思是 context 已知时，next token 的 conditional distribution（条件分布）。竖线右边是条件，不是输出。

## 7. Independent 与 mutually exclusive 不是近义词

若 events $A,B$ independent（独立），则：

$$
P(A\cap B)=P(A)P(B)
$$

这表示知道其中一个是否发生，不改变另一个的概率。

Mutually exclusive（互斥）表示它们不能同时发生：

$$
A\cap B=\varnothing
$$

两个概率都非零的互斥事件通常不独立。因为一旦知道 $A$ 发生，就已经确定 $B$ 不会发生。

当前只需要能用这条因果关系区分它们，不重做概率论证明。

## 8. PMF 与 PDF：token probability 属于哪一种

离散 random variable 使用 PMF（probability mass function，概率质量函数）：

$$
p_X(x)=P(X=x)
$$

每个 category 的 mass 可以直接相加，所有 categories 的总和为 `1`。

连续 random variable 使用 PDF（probability density function，概率密度函数）。单点 density 不是单点 probability；区间 probability 来自积分：

$$
P(a\le X\le b)
=
\int_a^b f_X(x)\,dx
$$

LLM 从有限 vocabulary 中选择 token，属于 categorical distribution（类别分布），使用的是离散 probability mass，不是连续 PDF。

## 9. 把分布交给 NumPy

NumPy 推荐使用独立 `Generator`：

```python
import numpy as np

rng = np.random.default_rng(seed=2026)
```

`seed` 决定 pseudo-random stream（伪随机序列）的起点。相同 NumPy 实现、相同 seed、相同调用顺序，通常会产生相同序列。

### 9.1 Bernoulli sampling

先产生 $[0,1)$ 上的 uniform samples（均匀样本）：

```python
uniform_values = rng.random(sample_count)
```

再判断是否小于 $p$：

```python
samples = (uniform_values < probability).astype(np.int64)
```

一个 uniform value 落进 `[0,p)` 的概率正好是 $p$，因此结果服从 Bernoulli distribution。

### 9.2 Categorical sampling

```python
probabilities = np.array([0.2, 0.3, 0.5], dtype=np.float64)

indices = rng.choice(
    3,
    size=sample_count,
    replace=True,
    p=probabilities,
)
```

`replace=True` 表示一次抽取不会永久拿走某个 category。模型生成 token 时也是每一步重新得到一条 distribution，并不是从 vocabulary 中抽走一个 token。

统计频率：

```python
counts = np.bincount(indices, minlength=3)
frequencies = counts / sample_count
```

`np.bincount` 接收 non-negative integer indices。若业务 categories 是 `[10,20,30]`，counts 的 array index 仍是 `0/1/2`，不能把 index 和业务 value 混成一个对象。

## 10. Prediction 与 sampling 是两种 policy

给定：

```text
[0.2, 0.3, 0.5]
```

Argmax prediction（最大值预测）总返回 index `2`：

```python
prediction = int(np.argmax(probabilities))
```

Categorical sampling 会偶尔返回 `0` 或 `1`，长期频率才接近 probabilities。

```text
probabilities：模型表达的不确定性
argmax：确定性决策 policy
sampling：按 distribution 随机抽取的 policy
selected index：这一次的最终结果
```

Greedy、temperature、top-k、top-p 留到 T19。T5 只建立对象边界：distribution 不是 sample，sample 也不是 probability vector。

## 11. Seed 能证明什么

下面两条 stream 应相同：

```python
rng_a = np.random.default_rng(2026)
rng_b = np.random.default_rng(2026)

np.testing.assert_array_equal(
    rng_a.random(10),
    rng_b.random(10),
)
```

这证明本实验在当前条件下可复现。它不证明：

```text
一个 seed 足以代表所有随机结果
不同 library/version/device 必然 bitwise identical
并发调用顺序改变后 stream 仍相同
NumPy PRNG 可用于密码学安全场景
```

Seed 是调试与实验控制工具，不是统计结论。

## 14. 与 AI Infra 的连接

典型 LLM decoding chain 是：

```text
model forward
-> logits
-> categorical probabilities
-> decoding / sampling policy
-> selected token index
```

T5 负责后半段的对象边界。T6 会补 `logits -> probabilities` 的 stable softmax；T19 再加入 temperature、top-k 与 top-p。

当 serving API 返回 token 时，系统里至少已经经过 model output、概率转换、policy 和随机状态四层。把它们都叫“模型给了一个概率”，后续 correctness、reproducibility 和性能分析都会失去主语。
