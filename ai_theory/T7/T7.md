# Part 1：理解对象后，独立闭合 training loop

## 0. 主问题

T7 第一次把此前对象组成反复运行的系统：

```text
data -> prediction -> loss -> gradient -> update -> next iteration
```

真实认知墙不是某一条 derivative，而是能否让 shapes、reduction、gradient signs 与 update order 同时正确。

## 1. 个人笔记复习索引

```text
matrix-vector multiplication
affine transformation
mean 与 squared error
partial derivative / gradient
chain rule
```

不重学线代与微积分。

## 2. training objects

```text
X: features, shape [N,D]
y: labels, shape [N]
w: weights, shape [D]
b: scalar bias
predictions: shape [N]
loss: scalar
grad_w: shape [D]
grad_b: scalar
```

model：

$$
\hat{\mathbf y}=X\mathbf w+b
$$

MSE：

$$
L=\frac1N\sum_{i=1}^{N}(\hat y_i-y_i)^2
$$

令 $\mathbf e=\hat{\mathbf y}-\mathbf y$：

$$
\nabla_{\mathbf w}L=\frac{2}{N}X^T\mathbf e,qquad
\frac{\partial L}{\partial b}=\frac{2}{N}\sum_i e_i
$$

update：

$$
\mathbf w\leftarrow\mathbf w-\eta\nabla_{\mathbf w}L,qquad
b\leftarrow b-\eta\frac{\partial L}{\partial b}
$$

`parameter` 是被训练更新的 state；`hyperparameter` 如 learning rate，由训练过程外部选择。

# Part 2：用证据判断训练是否真的正确

## 4. model、loss、optimizer 不应混成一个对象

```text
model：parameters -> predictions
loss：predictions + targets -> scalar objective
gradient computation：objective 对 parameters 的 sensitivity
optimizer/update rule：怎样使用 gradients 改 parameters
```

拆开后才能单独检查 prediction、loss、gradient 与 update。

## 5. full-batch 是什么

每次 update 使用全部 $N$ 个 samples，叫 full-batch gradient descent。mini-batch/SGD 留到 PyTorch 阶段。

`epoch` 是完整看过一次 dataset；`iteration` 是一次 parameter update。在 full-batch 情况下二者常一一对应，但不是普遍同义词。

## 6. loss 下降为什么不是充分证据

错误 gradient scale、错误 bias、甚至某些 broadcasting bug，也可能让特定 dataset 的 loss 暂时下降。

至少形成三层 evidence：

```text
local：forward/loss 固定输入结果正确
derivative：analytic gradient 与 T4 finite difference 一致
end-to-end：exact data 上 prediction 与 parameters 被恢复
```

parameter recovery 只适用于 identifiable、无噪声的 synthetic setup；真实 noisy data 不要求恢复唯一真值。

## 7. learning rate experiment

保持 data、initial parameters 与 iterations 相同，只改变 $\eta$：

```text
too small：下降慢
reasonable：稳定下降
too large：oscillation、increase 或 non-finite
```

`convergence` 不是“循环跑完”。你只能报告当前 stopping condition 与 observed loss behavior。

## 8. Round3 高价值补强

在同一文件加入：

1. 对一个 small case 抽查 `grad_w` 与 `grad_b` 的 finite difference。
2. 比较三种 learning rates。
3. 给 labels 加 small Gaussian noise，观察 final loss 不再接近 zero，并停止用 exact parameter recovery 当硬 oracle。

不需要复制第二套 training framework。

## 9. 与 AI Infra 的连接

```text
training path：forward + loss + backward + update + parameter mutation
inference path：loaded parameters + forward
```

batch、matrix operation 与 reduction 的选择同时影响 correctness、memory traffic 与 kernel design。NumPy reference 将来可用于验证 C++/CUDA/framework operator。
