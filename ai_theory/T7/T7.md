## 4. 两条路径共用的数学 contract

设：

```text
X [N,D]
w [D]
b scalar
y [N]
```

这里把 bias 单独写成 $b$。若 Ex1 使用一列全 `1` 把 bias 合并进设计矩阵，并用 $\theta[D+1]$ 表示 parameters，也属于同一模型；验收看 prediction、gradient 与 reference 是否一致，不强制改 representation。

Forward：

$$
\hat{\mathbf y}=X\mathbf w+b
$$

使用普通 mean convention 的 MSE：

$$
J(\mathbf w,b)=\frac{1}{N}\sum_{i=1}^{N}
(\hat y_i-y_i)^2
$$

对应 gradients：

$$
\nabla_{\mathbf w}J
=\frac{2}{N}X^T(\hat{\mathbf y}-\mathbf y)
$$

$$
\frac{\partial J}{\partial b}
=\frac{2}{N}\sum_{i=1}^{N}(\hat y_i-y_i)
$$

如果 Ex1 沿用原课程的 $\frac{1}{2N}$ convention，gradient 中没有前面的 `2`。两种 convention 都正确，但 objective、analytic gradient、检查值和 update 必须来自同一套定义。

## 5. 为什么一条下降曲线还不够

Training evidence 分三层：

### 5.1 Local Correctness（当前一步是否算对）

固定 parameters，对照：

```text
prediction values
cost checkpoint
gradient checkpoint 或 finite-difference spot check
```

它回答当前一步算得是否正确。

### 5.2 Trajectory Correctness（更新轨迹是否合理）

记录：

```text
initial loss
若干中间 loss
final loss
finite check
```

它回答 update loop 是否沿合理方向运行。

### 5.3 Final Behavior（最终预测是否正确）

对照：

```text
prediction
learned parameters
np.linalg.lstsq / normal-equation reference
```

它回答训练结果是否接近独立求解路径。

三层合在一起，比“loss 最后变小了”更有证明力。

你在 T6 刚经历了“固定例子能跑，但另一组 shape 或 dtype 暴露缺口”。这里继续用同一个原则：原题检查值负责局部结果，训练曲线负责更新轨迹，最小二乘负责另一条求解路径，三者各自提供不同证据。检查失败应明确让程序失败；已有 `np.testing.assert_allclose` 可以继续用，不另建测试工程。原题的近似打印值用匹配其精度的容差，不把两位小数当成完整精度的参考。

## 6. T7 真正新增的 AI Infra 映射

T6 中，你已经把 `max/exp/sum` 与具体数组、类别轴和中间 shape 对上了。现在看 Ex1：**每轮都读取训练数据和当前参数，产生预测与误差，再用误差算梯度，最后改参数。** 这是一轮 full-batch training（使用全部训练样本的一轮训练计算）：

```text
固定的 X [N,D]、y [N] + 当前 w [D]、b
-> X @ w + b，得到 predictions [N]
-> predictions - y，得到 residuals [N]
-> 平方误差求平均，得到本轮 scalar loss
-> X.T @ residuals 与误差求和，得到梯度 [D] + scalar
-> 用同一轮梯度同步更新 w、b
-> 新参数进入下一轮
```

`X @ w` 是 GEMV（General Matrix-Vector Multiplication，矩阵与向量乘法）：每行与同一组权重做点积，得到每个样本的预测。`X.T @ residuals` 则把各样本的误差贡献汇总到每个权重上。这里各步的缩放系数沿用 §4 中你选定的 objective（目标函数），不是另换一套梯度定义。

这些数组分别由谁继续使用？

| 对象 | 本轮作用 | 下一轮或预测新样本时怎样使用 |
|---|---|---|
| `X`、`y` | 提供固定训练数据和真实答案 | 训练中复用；预测新样本时换成新的输入，预测动作不需要真实答案 |
| `w`、`b` | 决定当前预测 | 更新后保留到下一轮；预测新样本也需要已学到的参数 |
| predictions、residuals | 保存当前预测与误差 | 对应当前参数，更新后下一轮重新计算 |
| gradients | 指明本轮参数更新 | 本轮更新使用，下一轮重新计算 |
| loss | 为当前预测计分 | 可以记录成训练曲线；单纯给新输入算预测时不需要它 |

**训练包含“读取答案、算梯度、改参数”；推理读取已经学好的参数，为新输入计算预测。** 每个 buffer（保存数组数据的内存区域）的 shape 和存活时间因此不同。今天只把这张对象图接到自己的实现，不要求写内存管理器或做性能测试。

以后进入 MLP、Transformer 和 inference serving 时，模型会更复杂，但仍然要回答：

```text
当前有哪些 tensors
每个 tensor 的 shape / dtype / bytes 是什么
谁读取、谁写入
哪些对象只在 training 存在
哪些对象必须由 inference runtime 保存
```

你只需拿自己那份 Ex1 实现回答这些对象关系，不再抄一份相同的线性回归推导。词表分类和 logits-space loss 会在 T8 用到你已通过的 T6；T7 先把完整训练循环完成。
