## 4. 两条路径共用的数学 contract

设：

```text
X [N,D]
w [D]
b scalar
y [N]
```

这里把 bias 单独写成 $b$。若 Ex1 使用一列全 `1` 把 bias 合并进设计矩阵，并用 $\theta[D+1]$ 表示 parameters，也属于同一模型；验收看 prediction、gradient 与 reference 是否一致，不强制改 representation。

Forward：

$$
\hat{\mathbf y}=X\mathbf w+b
$$

使用普通 mean convention 的 MSE：

$$
J(\mathbf w,b)=\frac{1}{N}\sum_{i=1}^{N}
(\hat y_i-y_i)^2
$$

对应 gradients：

$$
\nabla_{\mathbf w}J
=\frac{2}{N}X^T(\hat{\mathbf y}-\mathbf y)
$$

$$
\frac{\partial J}{\partial b}
=\frac{2}{N}\sum_{i=1}^{N}(\hat y_i-y_i)
$$

如果 Ex1 沿用原课程的 $\frac{1}{2N}$ convention，gradient 中没有前面的 `2`。两种 convention 都正确，但 objective、analytic gradient、检查值和 update 必须来自同一套定义。

## 5. 为什么一条下降曲线还不够

Training evidence 分三层：

### 5.1 Local correctness

固定 parameters，对照：

```text
prediction values
cost checkpoint
gradient checkpoint 或 finite-difference spot check
```

它回答当前一步算得是否正确。

### 5.2 Trajectory correctness

记录：

```text
initial loss
若干中间 loss
final loss
finite check
```

它回答 update loop 是否沿合理方向运行。

### 5.3 Final behavior

对照：

```text
prediction
learned parameters
np.linalg.lstsq / normal-equation reference
```

它回答训练结果是否接近独立求解路径。

三层合在一起，比“loss 最后变小了”更有证明力。

## 6. T7 真正新增的 AI Infra 映射

一轮 full-batch training 的主要数据流是：

```text
X [N,D]
-> GEMV / GEMM-like forward
-> prediction buffer [N]
-> residual buffer [N]
-> reductions
-> parameter gradients [D] + scalar
-> parameter update
```

这里第一次把模型数学转换成系统对象：

- `X`、predictions、residuals 和 gradients 都占内存。
- Forward、gradient 和 reduction 具有不同的 shape 与访存行为。
- Training 需要 target、loss、gradient 和 update state。
- Inference 只保留 input、parameters、forward intermediates 与 output。

以后进入 MLP、Transformer 和 inference serving 时，模型会更复杂，但仍然要回答：

```text
当前有哪些 tensors
每个 tensor 的 shape / dtype / bytes 是什么
谁读取、谁写入
哪些对象只在 training 存在
哪些对象必须由 inference runtime 保存
```

这才是 T7 相比传统机器学习课程需要额外留下的部分。
