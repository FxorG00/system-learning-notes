## 1. 从 C++ 的 `vector` 出发

你看到：

```cpp
std::vector<float> values(24);
```

会自然知道：

```text
element type：float
element count：24
memory：由 vector 管理
indexing：values[i]
```

但模型中的数据经常不只是一条一维序列。例如 24 个浮点数可能表示：

```text
2 个 batches
每个 batch 有 3 个 tokens
每个 token 有 4 个 features
```

于是同样 24 个数可以被描述为：

```python
x.shape == (2, 3, 4)
```

这里多出来的不是 24 个新数据，而是“一套怎样解释这些数据的位置”的结构。

NumPy 的核心对象 `ndarray` 就把两类信息放在一起：

```text
element data
+
描述与访问 data 的 metadata
```

后面我们会具体看到：

```text
shape：每个 axis 有多长
ndim：一共有多少个 axes
size：总共有多少个 elements
dtype：每个 element 应按什么类型解释
itemsize：每个 element 占多少 bytes
nbytes：全部 element data 占多少 bytes
```

这套语言以后会原样迁移到 PyTorch Tensor、activation、attention 和 KV Cache。

## 3. 第一个 NumPy 程序

创建临时文件或者直接进入 Python REPL：

```python
import numpy as np

values = np.array([1, 2, 3], dtype=np.int32)
print(values)
print(type(values))
```

`import numpy as np` 的含义是：

```text
numpy：被导入的 package
np：当前 Python 文件给它取的 alias
np.array：访问 NumPy package 暴露的 array function
```

输出中的类型是：

```text
numpy.ndarray
```

`ndarray` 是 N-dimensional array，即 N 维数组。它不是“只能二维”的矩阵类，`N` 可以是 1、2、3，也可以更高。

NumPy 主要面向大量同类型数值数据。普通 Python list 更通用，可以同时放 integer、string 和任意 object；数值 `ndarray` 通常使用统一的 `dtype`，shape 也是规则的，而不是 jagged 的锯齿结构。

例如：

```python
python_values = [1, 2, 3]
numpy_values = np.array([1, 2, 3], dtype=np.int32)

print(python_values * 2)
print(numpy_values * 2)
```

结果不同：

```text
list * 2
-> 重复 sequence
-> [1, 2, 3, 1, 2, 3]

ndarray * 2
-> 每个 element 分别乘 2
-> [2, 4, 6]
```

这就是 NumPy 的第一种“批量数值操作”语义。

官方查证，可选：

- [NumPy Absolute Basics：Why use NumPy?](https://numpy.org/doc/stable/user/absolute_beginners.html#why-use-numpy)
- [NumPy Absolute Basics：What is an array?](https://numpy.org/doc/stable/user/absolute_beginners.html#what-is-an-array)

## 4. `shape`：多维数据的位置说明书

先创建 24 个连续整数，再把它们解释成三维结构：

```python
x = np.arange(24, dtype=np.float32).reshape(2, 3, 4)
print(x)
print(x.shape)
```

`shape == (2, 3, 4)` 的准确读法是：

```text
x 有 3 个 axes
axis 0 的 extent 是 2
axis 1 的 extent 是 3
axis 2 的 extent 是 4
```

### 4.1 dimension、axis、extent

`dimension` 表示维度。

`axis` 表示某一个被编号的维度。编号从 0 开始。

`extent` 表示这个 axis 上有多少个可用位置。

对于 `(2, 3, 4)`：

```text
axis 0: indices 0~1
axis 1: indices 0~2
axis 2: indices 0~3
```

不要把 `axis` 永远翻译成“行”或“列”。二维表格可以方便地说行列，但模型数据更常写成：

```text
[batch, sequence, hidden]
```

此时：

```text
axis 0 -> batch
axis 1 -> sequence
axis 2 -> hidden
```

这些业务名字来自当前数据含义；`axis 0/1/2` 来自数组自身的位置结构。

### 4.2 一维 shape 为什么是 `(6,)`

```python
line = np.arange(6)
print(line.shape)  # (6,)
```

Python 中：

```text
(6,) -> 只含一个 element 的 tuple
(6)  -> integer 6 外面加括号
```

所以一维 array 的 shape 写成 `(6,)`，结尾逗号不是 NumPy 的特殊语法，而是 Python 单元素 tuple 的语法。

## 5. 六个 metadata 连成一个对象模型

仍然使用：

```python
x = np.arange(24, dtype=np.float32).reshape(2, 3, 4)
```

逐个观察：

```python
print(x.shape)
print(x.ndim)
print(x.size)
print(x.dtype)
print(x.itemsize)
print(x.nbytes)
```

预期：

```text
shape    -> (2, 3, 4)
ndim     -> 3
size     -> 24
dtype    -> float32
itemsize -> 4
nbytes   -> 96
```

它们不是六个互不相关的记忆点。

### 5.1 `ndim` 与 `shape`

`ndim` 是 number of dimensions，即 axis 数量：

$$
\text{ndim}=\operatorname{len}(\text{shape})
$$

本例 shape 有三个 extent，所以 `ndim == 3`。

### 5.2 `size` 与 `shape`

`size` 是 element 总数，等于所有 extents 的乘积：

$$
\text{size}=\prod_i \text{shape}_i
$$

本例：

$$
2\times3\times4=24
$$

### 5.3 `dtype` 与 `itemsize`

`dtype` 是 data type，表示每个 element 的 bytes 应怎样解释。

```text
int32   -> 32 bits -> 4 bytes
float32 -> 32 bits -> 4 bytes
float64 -> 64 bits -> 8 bytes
```

`itemsize` 直接给出一个 element 占多少 bytes。

为了让测试和内存估算跨环境稳定，学习代码中尽量显式写 `dtype=np.int32` 或 `dtype=np.float32`，不要依赖默认整数位宽。

### 5.4 `nbytes`

`nbytes` 是 array element data 占用的 bytes：

$$
\text{nbytes}=\text{size}\times\text{itemsize}
$$

本例：

$$
24\times4=96\text{ bytes}
$$

它不包括 Python object 自身、allocator metadata 和其他关联对象的全部内存。

把三个关系放进代码：

```python
import math

assert x.ndim == len(x.shape)
assert x.size == math.prod(x.shape)
assert x.nbytes == x.size * x.itemsize
```

`assert condition` 在 condition 为 false 时抛出 `AssertionError`。T1 用它做小型 correctness oracle；不要用 `python -O` 运行，因为 optimization mode 会移除普通 `assert`。

官方查证，可选：

- [NumPy Absolute Basics：Array attributes](https://numpy.org/doc/stable/user/absolute_beginners.html#array-attributes)
- [The N-dimensional array](https://numpy.org/doc/stable/reference/arrays.ndarray.html)

## 6. 怎样创建数组

T1 只需要四种入口。

### 6.1 从已有 Python 数据创建：`np.array`

```python
values = np.array([10, 20, 30], dtype=np.int32)
grid = np.array(
    [[1.0, 2.0], [3.0, 4.0]],
    dtype=np.float32,
)
```

`np.array(object, dtype=...)` 接收 list 或 nested list，并创建 `ndarray`。

### 6.2 按 shape 填 0 或 1

```python
zero_grid = np.zeros((2, 3), dtype=np.float32)
one_line = np.ones(4, dtype=np.int32)
```

`shape` 可以是 integer，也可以是 tuple。这里显式写 dtype，不依赖默认 floating type。

### 6.3 创建半开数值序列：`np.arange`

```python
values = np.arange(2, 9, 2, dtype=np.int32)
print(values)  # [2 4 6 8]
```

和 C++ 半开区间习惯相似：

```text
start = 2
stop  = 9，不包含
step  = 2
```

T1 只对 integer `arange` 建模；浮点 step 与 `linspace` 以后需要时再讲。

### 6.4 先创建一维，再 reshape

```python
x = np.arange(24, dtype=np.int32).reshape(2, 3, 4)
```

数据值是 `0~23`，shape 则从 `(24,)` 变为 `(2, 3, 4)`。

## 7. Indexing：沿每个 axis 选择位置

仍使用：

```python
x = np.arange(24, dtype=np.int32).reshape(2, 3, 4)
```

### 7.1 取一个 element

```python
value = x[1, 2, 3]
assert value == 23
```

三个 index 分别作用在三个 axes：

```text
axis 0 -> index 1
axis 1 -> index 2
axis 2 -> index 3
```

每个 axis 都被固定到一个位置，因此结果不再有剩余 axis，而是一个 scalar value。

### 7.2 Integer index 会消耗一个 axis

```python
page = x[0]
assert page.shape == (3, 4)
```

输入 shape 是 `(2, 3, 4)`。`x[0]` 固定 axis 0，剩下 axis 1 与 axis 2，所以结果 shape 是 `(3, 4)`。

### 7.3 冒号保留对应 axis

```python
middle = x[:, 1, :]
assert middle.shape == (2, 4)
```

逐项读：

```text
:  -> 保留 axis 0，extent 仍为 2
1  -> 固定 axis 1，integer index 消耗这个 axis
:  -> 保留 axis 2，extent 仍为 4
```

所以输出 shape 是 `(2, 4)`。

这比背“取第几行”更能迁移到模型代码。以后面对 `[batch, sequence, hidden]`，`x[:, 1, :]` 就表示保留所有 batches，固定一个 sequence position，保留全部 hidden features。

## 8. Reduction：`axis` 到底控制什么

`reduction` 是“把一组 values 聚合成更少 values”的操作，例如 `sum`、`mean`、`max`。

考虑：

```python
x = np.arange(24, dtype=np.int32).reshape(2, 3, 4)
y = x.sum(axis=1)
print(y.shape)  # (2, 4)
```

`axis=1` 的含义不是“固定做行求和”，而是：

> 沿输入 shape 的第 1 个 axis 聚合。

输入 `(2, 3, 4)` 中 axis 1 的 extent 是 3。每个输出位置把这三个 values 相加：

$$
y[i,k]=\sum_{j=0}^{2}x[i,j,k]
$$

被聚合的 axis 1 从输出 shape 中消失：

```text
input : (2, 3, 4)
          ^
          aggregate axis 1

output: (2, 4)
```

你现在不需要背所有 reduction API，但要形成一条读法：

```text
先写 input shape
-> 找到被操作的 axis
-> 判断它是被保留、改变还是消失
-> 推出 output shape
```

## 9. Elementwise operation：shape 不变，values 改变

`elementwise` 是逐元素运算。

```python
left = np.array([1, 2, 3], dtype=np.int32)
right = np.array([10, 20, 30], dtype=np.int32)

added = left + right
multiplied = left * right

assert np.array_equal(added, np.array([11, 22, 33], dtype=np.int32))
assert np.array_equal(multiplied, np.array([10, 40, 90], dtype=np.int32))
```

相同 logical position 上的 values 参与同一次操作：

```text
left[i] and right[i]
        |
        v
     operator
        |
        v
    result[i]
```

在以上 same-shape 情况下：

```text
input shape  -> (3,)
output shape -> (3,)
```

`left * right` 是 elementwise multiplication，不是矩阵乘法。不同 shape 怎样自动匹配属于 broadcasting，统一留到 T3。

## 10. Reshape：改变解释方式，不改变 element count

```python
source = np.arange(12, dtype=np.int32)
matrix = source.reshape(3, 4)
```

reshape 合法的核心条件是：

$$
\text{old element count}=\prod_i \text{new shape}_i
$$

本例：

$$
12=3\times4
$$

所以以下 shape 都兼容：

```python
source.reshape(2, 6)
source.reshape(2, 2, 3)
source.reshape(3, -1)
```

`-1` 表示让 NumPy 根据总 element count 和其他 extents 推导这一项。一次 reshape 最多有一个 `-1`。

下面不兼容：

```python
source.reshape(5, 3)
```

因为 `12 != 5 * 3`。NumPy 会抛 `ValueError`，不会自动补 0 或制造三个新 elements。

可以主动验证这个错误：

```python
error_seen = False

try:
    source.reshape(5, 3)
except ValueError:
    error_seen = True

assert error_seen
```

`try/except` 与 C++ `try/catch` 的职责相近：这里不是忽略所有异常，而是确认“不兼容 shape 必须被拒绝”。

最后保留一个边界：`reshape` 返回新的 array object，但它可能和原 array 共享 data，也可能因 layout 产生 copy。T1 不把 reshape 简化成“一定零拷贝”。

官方查证，可选：

- [NumPy Absolute Basics：Can you reshape an array?](https://numpy.org/doc/stable/user/absolute_beginners.html#can-you-reshape-an-array)

## 11. Slice 是 view：两个对象可能指向同一份 data

这是 T1 最值得亲手观察的一次实验。

```python
original = np.arange(6, dtype=np.int32)
window = original[2:5]

window[0] = 99

print(original)  # [ 0  1 99  3  4  5]
print(window)    # [99  3  4]
```

发生的不是“NumPy 神秘地同步了两个数组”，而是：

```text
original ndarray object
        |
        +----\
              shared element data
        +----/
window ndarray view
```

basic slicing 通常产生 `view`。view 是新的 ndarray object，但它引用 original 的一部分 data，所以通过 view 修改 element 会影响 original。

如果需要独立 data，显式复制：

```python
independent = original[2:5].copy()
independent[0] = -1

assert original[2] == 99
assert independent[0] == -1
```

现在只建立这条边界：

```text
new ndarray object != guaranteed new storage
```

完整 copies/views、`base`、stride 与 contiguous layout 后面再学。

官方查证，可选：

- [NumPy Absolute Basics：Array fundamentals](https://numpy.org/doc/stable/user/absolute_beginners.html#array-fundamentals)
- [NumPy Copies and Views](https://numpy.org/doc/stable/user/basics.copies.html)

## 12. 把整条数据流串起来

手推：

```python
x = np.arange(24, dtype=np.float32).reshape(2, 3, 4)
y = x[:, 1, :]
z = y * 2
r = z.sum(axis=1)
```

不要从最后输出反猜，按步骤追踪：

```text
np.arange(24, dtype=float32)
-> 24 elements
-> shape (24,)
-> 24 * 4 = 96 bytes of element data

reshape(2, 3, 4)
-> 2 * 3 * 4 == 24
-> x.shape == (2, 3, 4)

x[:, 1, :]
-> keep axis 0
-> consume axis 1 with integer index
-> keep axis 2
-> y.shape == (2, 4)

y * 2
-> scalar elementwise operation
-> z.shape == (2, 4)
-> z.dtype == float32

z.sum(axis=1)
-> aggregate the extent-4 axis
-> r.shape == (2,)
```

这条链就是以后读模型代码的基本动作：

```text
当前对象是什么？
-> input shape / dtype 是什么？
-> operation 改了 values、shape，还是两者都改？
-> output shape / dtype 是什么？
-> 是否新分配或共享 storage？
```

T1 只完整回答前三项，并对 storage 建立第一层警觉。

## 15. 这和 AI Infra 有什么关系

以后看到 activation：

```text
shape = [B, S, H]
dtype = float32
```

最基础的 element data estimate 是：

$$
\text{bytes}=B\times S\times H\times4
$$

例如：

```text
shape = (2, 3, 4)
dtype = float32

element count = 24
bytes per element = 4
element data = 96 bytes
```

以后分析：

```text
batching
padding
attention activation
KV Cache
CPU/GPU transfer
operator correctness
```

都会先问：

```text
shape 是什么？
dtype 是什么？
operation 沿哪些 axes 发生？
产生多少 elements？
这些 elements 占多少 bytes？
```

NumPy 在这条路线里的角色主要是 correctness reference。以后实现 C++/CUDA operator，可以先用小规模 NumPy 计算建立容易解释的 expected result，再比较底层实现。
