# Session A：从 C++ object 走到 NumPy ndarray

## 1. 当前问题

在 C++ 中看到：

```cpp
std::vector<float> values(24);
```

你至少会问：

```text
元素 type 是什么？
有多少 elements？
谁拥有 memory？
怎样访问第 i 个 element？
```

以后在模型代码中会不断看到：

```python
x.shape == (2, 3, 4)
x.dtype == np.float32
```

如果只把它看成“一个三层 list”，后续的 Tensor、Attention、KV Cache 和显存估算都会失去统一语言。

T1 要建立的对象模型是：

```text
ndarray object
    |
    +--> shape：每个 axis 的 extent
    +--> ndim：axis 数量
    +--> size：总 element 数
    +--> dtype：每个 element 怎样解释
    +--> itemsize：每个 element 占多少 bytes
    +--> data：实际 element data，可能由自己拥有，也可能与别的 array 共享
```

今天先理解这些 metadata 与基本操作，不深入 data pointer、stride 和 view ownership 的全部规则。

## 5. 必要术语

### 5.1 NumPy

`NumPy` 来源于 Numerical Python，可理解为 Python 数值计算基础库。

当前作用：提供 `ndarray` 和对 array 的批量操作。

它不是：

```text
深度学习框架
GPU 编程语言
自动微分系统
数据库
```

### 5.2 ndarray

`ndarray`：N-dimensional array，N 维数组。

当前作用：保存同一种 `dtype` 的 fixed-size elements，并用多维 indexing scheme 访问。

它不等同于 Python nested list。不同 ndarray 还可能共享同一份 data。

### 5.3 dimension / axis / extent

```text
dimension：维度
axis：某一个被编号的维度
extent：这个 axis 上有多少个位置
```

对于：

```python
x.shape == (2, 3, 4)
```

应该读成：

```text
x 有 3 个 dimensions，所以 ndim == 3
axis 0 的 extent 是 2
axis 1 的 extent 是 3
axis 2 的 extent 是 4
```

`axis` 不是永远等于“行”或“列”。行列只是 2D array 下的方便说法；到了 `[batch, sequence, hidden]`，继续用 axis 更稳。

### 5.4 shape

`shape`：形状。

它是由每个 axis extent 组成的 tuple：

```python
(2, 3, 4)
```

注意 1D shape：

```python
(6,)
```

末尾逗号表示这是只含一个 element 的 tuple；`(6)` 只是整数 `6` 外面加括号。

### 5.5 dtype

`dtype`：data type，元素数据类型。

它回答：

```text
每个固定大小的 element 占多少 bytes？
这些 bytes 应解释成 int、float 还是其他值？
```

例如：

```text
np.int32：通常每个 element 4 bytes
np.float32：每个 element 4 bytes
np.float64：每个 element 8 bytes
```

### 5.6 elementwise

`elementwise`：逐元素。

```python
a * b
```

在本日相同 shape arrays 上表示对应位置相乘，不是矩阵乘法。矩阵乘法留到 T3。

### 5.7 reshape

`reshape`：重新描述形状。

当前作用：在 element 总数兼容时返回具有新 shape 的 array。

它不代表：

```text
增加 elements
删除 elements
自动补 0
一定复制 data
```

## 6. Python list 与 ndarray 的关键差异

先看 Python list：

```python
values = [1, 2, 3]
print(values * 2)
```

结果是把 sequence 重复两次：

```text
[1, 2, 3, 1, 2, 3]
```

再看 ndarray：

```python
import numpy as np

values = np.array([1, 2, 3], dtype=np.int32)
print(values * 2)
```

结果是逐元素乘法：

```text
[2 4 6]
```

当前先建立以下对比：

| Python list | NumPy ndarray |
|---|---|
| 可以混合保存不同 Python object references | 通常保存同一 dtype、同一 item size 的 elements |
| `list * 2` 重复 sequence | `array * 2` 对每个 element 计算 |
| nested list 可以 jagged | 常规 numerical ndarray 的 shape 必须规则 |
| 切片产生新的 list | basic ndarray slice 通常是共享 data 的 view |

“ndarray 一定连续”不是 T1 可以随便下的结论。NumPy array 可以是 view，也可以使用不同 stride；这留到后续 layout 课程。

## 7. 创建 ndarray 的最小 API

下面的 signature 是 T1 使用形态，不是完整 NumPy API declaration。

### 7.1 `np.array`

```python
np.array(object, dtype=None)
```

参数：

```text
object：用于创建 array 的 Python object，常见是 list / nested list
dtype：可选，显式指定 element type
```

返回：新的 `ndarray` object。

小例子：

```python
values = np.array([10, 20, 30], dtype=np.int32)
print(values.shape)  # (3,)
print(values.dtype)  # int32
```

### 7.2 `np.zeros` / `np.ones`

```python
np.zeros(shape, dtype=float)
np.ones(shape, dtype=float)
```

`shape` 可以是 integer 或 tuple。

```python
zero_grid = np.zeros((2, 3), dtype=np.float32)
one_line = np.ones(4, dtype=np.int32)
```

注意默认 `dtype=float`；若测试和内存估算需要稳定结果，应显式写 dtype。

### 7.3 `np.arange`

```python
np.arange(stop)
np.arange(start, stop, step=1, dtype=None)
```

它创建半开区间风格的数值序列：

```python
values = np.arange(2, 9, 2, dtype=np.int32)
print(values)  # [2 4 6 8]
```

T1 只用 integer `arange`。浮点步长的累计误差与 `linspace` 以后需要时再处理。

## 8. 六个核心属性与 invariant

```python
x = np.arange(24, dtype=np.float32).reshape(2, 3, 4)
```

当前必须能够推导：

```text
x.shape    == (2, 3, 4)
x.ndim     == 3
x.size     == 24
x.dtype    == np.float32
x.itemsize == 4
x.nbytes   == 96
```

核心 invariant：

```python
assert x.ndim == len(x.shape)
assert x.size == 2 * 3 * 4
assert x.nbytes == x.size * x.itemsize
```

`nbytes` 只统计 array elements 占用的 bytes，不是整个 Python object、allocator metadata 和所有关联对象的总内存。

这已经是 AI Infra 的第一条 memory estimation：

```text
element count * bytes per element = data bytes
```

## 9. indexing、slicing 与 axis 第一层

仍使用：

```python
x = np.arange(24).reshape(2, 3, 4)
```

### 9.1 单个 element

```python
x[1, 2, 3]
```

索引沿三个 axes 分别取：

```text
axis 0 index 1
axis 1 index 2
axis 2 index 3
```

结果是最后一个 element `23`。

### 9.2 取一个较低维 slice

```python
x[0]
```

axis 0 被一个具体 integer index 消耗掉，结果 shape 是：

```text
(3, 4)
```

```python
x[:, 1, :]
```

保留 axis 0 和 axis 2，固定 axis 1，结果 shape 是：

```text
(2, 4)
```

这里的 `:` 表示这个 axis 上选择当前范围内的所有 positions。

### 9.3 reduction 中的 axis

```python
result = x.sum(axis=1)
```

本日只记第一层：沿 axis 1 把这个维度聚合掉。

```text
input shape： (2, 3, 4)
remove axis 1
output shape：(2, 4)
```

不要死记“axis=0 是列求和”。先看 shape，并问“哪一个 axis 被操作掉”。

## 10. elementwise operation

对于两个相同 shape arrays：

```python
left = np.array([1, 2, 3], dtype=np.int32)
right = np.array([10, 20, 30], dtype=np.int32)

added = left + right
multiplied = left * right
```

结果：

```text
added     == [11, 22, 33]
multiplied == [10, 40, 90]
```

数据流：

```text
left[i] and right[i]
        |
        v
apply operator at the same logical position
        |
        v
result[i]
```

今天只要求 same-shape elementwise 和 array/scalar 操作。不同 shape 如何匹配属于 broadcasting，T3 再系统学习。

## 11. reshape 的契约

```python
source = np.arange(12)
matrix = source.reshape(3, 4)
```

合法的必要条件：

```text
old element count == new shape product
12 == 3 * 4
```

因此下面也合法：

```python
source.reshape(2, 6)
source.reshape(2, 2, 3)
source.reshape(3, -1)
```

`-1` 表示让 NumPy 根据其他 dimensions 和总 element 数推导一个 extent。一次 reshape 中最多让一个 dimension 使用 `-1`。

下面不合法：

```python
source.reshape(5, 3)
```

因为：

```text
source.size == 12
5 * 3 == 15
```

NumPy 会抛 `ValueError`，不会自动补三个 elements。

`reshape` 返回新的 array object；它可能与原 array 共享 data，也可能因 layout 需要产生 copy。T1 不把“reshape 一定零拷贝”写进 contract。

## 14. 五个常见误区

### 14.1 `(6,)` 不是 `(6)`

```text
(6,)：一个 element 的 tuple，是合法 1D shape
(6)：integer 6
```

### 14.2 axis 不是固定的“行列按钮”

对 `(2, 3, 4)`：

```text
axis 0 / 1 / 2 分别对应 shape tuple 的第 0 / 1 / 2 项
```

先按 shape tuple 定位，再谈它在当前业务中叫 batch、row 还是 hidden。

### 14.3 不显式 dtype，测试可能依赖平台默认值

```python
np.array([1, 2, 3])
```

会推导 integer dtype，但不要在跨环境测试中想当然地把它写死为某一个位宽。T1 固定测试使用 `np.int32` / `np.float32`。

### 14.4 `*` 不等于矩阵乘法

```python
left * right
```

是 elementwise multiplication。矩阵乘法使用其他 API，并要求数学 shape compatibility；T3 再学。

### 14.5 slice 与 reshape 不自动等于独立 data ownership

basic slicing 通常产生 view，修改 slice 可能影响原 array。`reshape` 也可能共享原 data。

所以看到两个 ndarray objects，不代表一定有两份 elements memory。T1 只建立警觉，完整 view/copy/stride 留到后续。

## 15. 用一条 shape 因果链检查自己

手推：

```python
x = np.arange(24, dtype=np.float32).reshape(2, 3, 4)
y = x[:, 1, :]
z = y * 2
```

完整链：

```text
np.arange(24)
-> 24 elements
-> initial shape (24,)

reshape(2, 3, 4)
-> 2 * 3 * 4 == 24
-> x.shape == (2, 3, 4)

x[:, 1, :]
-> keep axis 0
-> fix axis 1 at index 1
-> keep axis 2
-> y.shape == (2, 4)

y * 2
-> scalar applied elementwise
-> z.shape remains (2, 4)
-> z.dtype remains float32 in this case
```

以后读 Tensor code 时，也要用这种方式逐步追 shape，而不是看最后输出猜中间发生了什么。

## 17. 这和 AI Infra 有什么关系

以后看到模型 activation：

```text
shape = [B, S, H]
dtype = float32
```

第一层 memory estimate 就是：

```text
element count = B * S * H
bytes = B * S * H * 4
```

例如 T1 的：

```text
shape = (2, 3, 4)
dtype = float32
```

对应：

```text
24 elements
4 bytes per element
96 bytes of element data
```

后续的：

```text
KV Cache memory
batching
padding
operator correctness
```

## 20. 今日压缩记忆

```text
ndarray 是带 shape、dtype 和 indexing metadata 的 N-dimensional array object。

ndim == len(shape)
size == product(shape)
nbytes == size * itemsize

axis 是 shape tuple 中被编号的 dimension，
不是永远固定的“行”或“列”。

reshape 改变 shape 描述，但必须保持 element count compatible；
elementwise operation 按对应 element 计算，不等于 matrix multiplication。
```
