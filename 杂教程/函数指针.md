函数指针的通用语法是：

```cpp
返回类型 (*指针变量名)(参数类型列表);
```

比如普通函数：

```cpp
bool test_a(std::size_t workers, std::size_t iterations) {
    return true;
}
```

它的函数类型可以理解为：

```cpp
bool(std::size_t, std::size_t)
```

那么指向这种函数的指针写成：

```cpp
bool (*test_function)(std::size_t, std::size_t);
```

拆开看：

```cpp
bool
    这个函数最终返回 bool

(*test_function)
    test_function 是“指针变量”
    星号表示它指向函数
    括号必须有

(std::size_t, std::size_t)
    它指向的函数要接收两个 size_t 参数
```

使用：

```cpp
bool (*test_function)(std::size_t, std::size_t) = test_a;

bool passed = test_function(4, 100000);
```

也可以显式写解引用，效果相同：

```cpp
bool passed = (*test_function)(4, 100000);
```

实际工程里更建议起别名，不然这一串长得像 C++ 在发脾气：

```cpp
using TestFunction = bool (*)(std::size_t, std::size_t);

TestFunction test_function = test_a;
```

然后函数参数里就是：

```cpp
void run(TestFunction test_function) {
    test_function(4, 100000);
}
```

注意这个常见坑：

```cpp
bool *test_function(std::size_t, std::size_t);
```

这表示“一个函数，返回 `bool*`”，不是函数指针。

关键就是 `*` 和变量名外面的括号：

```cpp
bool (*test_function)(...)
```
