不需要先学编译原理。你现在把 `#include` 理解成**编译前的文本展开**就够了。

现在有两个文件：

```text
unique_fd.hpp
copyfile.cpp
```

`copyfile.cpp` 里写：

```cpp
#include "unique_fd.hpp"
```

## 第一阶段：预处理

在正式编译前，预处理器会找到 `unique_fd.hpp`，把它的内容展开到当前位置。

你写的是：

```cpp
#include "unique_fd.hpp"

int main() {
    UniqueFd fd(...);
}
```

预处理后可以近似理解成：

```cpp
class UniqueFd {
    // unique_fd.hpp 里的完整内容
};

int main() {
    UniqueFd fd(...);
}
```

不是真的修改了原文件，只是编译器接下来看到的内容类似于此。

因此编译器处理 `main()` 时，已经知道：

```text
UniqueFd 是什么类
有哪些成员函数
能否拷贝、能否移动
```

## 第二阶段：编译

运行：

```bash
g++ -std=c++17 -Wall -Wextra -g -c copyfile.cpp -o copyfile.o
```

编译器会把预处理后的 C++ 代码转换成目标文件：

```text
copyfile.cpp
+ 展开的 unique_fd.hpp
        ↓
    copyfile.o
```

`copyfile.o` 已经包含机器代码，但还不是最终可执行文件。

## 第三阶段：链接

然后链接器把：

```text
copyfile.o
C++ 标准库
C 标准库
open/read/write/close 等函数的实现
```

组合成最终程序：

```text
copyfile
```

平时写的命令：

```bash
g++ -std=c++17 -Wall -Wextra -g copyfile.cpp -o copyfile
```

实际上让 `g++` 帮你连续完成了：

```text
预处理 → 编译 → 汇编 → 链接
```

## 为什么不用单独编译 unique_fd.hpp？

因为当前的 `UniqueFd` 是 **header-only（仅头文件实现）**：

```cpp
class UniqueFd {
public:
    int get() const noexcept {
        return fd_;
    }
};
```

成员函数的实现全部写在类定义内部。`copyfile.cpp` 包含这个头文件后，就已经获得了完整实现。

所以只需要：

```bash
g++ copyfile.cpp -o copyfile
```

不需要：

```bash
g++ unique_fd.hpp ...
```

头文件一般不是独立的编译单元。

## `#include "..."` 和 `<...>` 的区别

```cpp
#include "unique_fd.hpp"
```

通常优先从当前项目、当前文件附近寻找，适合自己的头文件。

```cpp
#include <unistd.h>
```

通常从编译器配置的系统头文件目录寻找，适合系统库和标准库头文件。

## `#pragma once` 是干什么的？

`unique_fd.hpp` 开头有：

```cpp
#pragma once
```

意思是：

> 在同一个 `.cpp` 的预处理过程中，这个头文件只展开一次。

避免这种情况：

```text
copyfile.cpp
→ 包含 a.hpp
   → a.hpp 又包含 unique_fd.hpp

copyfile.cpp
→ 又直接包含 unique_fd.hpp
```

没有保护的话，`UniqueFd` 可能被重复定义。

## 可以亲眼观察

运行：

```bash
g++ -std=c++17 -E copyfile.cpp > copyfile.i
```

`-E` 表示只进行预处理。打开 `copyfile.i`，能看到 `unique_fd.hpp` 和其他系统头文件展开后的结果。

不过它会非常长，因为：

```text
copyfile.cpp
→ unique_fd.hpp
→ unistd.h
→ 其他系统头文件
→ 更多头文件
```

你现在记住这张图就够了：

```text
copyfile.cpp
    ↓ 遇到 #include "unique_fd.hpp"
展开 UniqueFd 的定义
    ↓
编译成 copyfile.o
    ↓
链接系统库
    ↓
生成 copyfile
```

所以我们选择 `unique_fd.hpp` 的原因就是：**`UniqueFd` 只实现一次，其他 `.cpp` 通过 `#include` 使用，不需要复制粘贴类代码。**
