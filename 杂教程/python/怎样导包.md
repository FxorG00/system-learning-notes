**从截图看，是导入路径的问题：`stable_softmax.py` 在 `t06` 里，而你当前代码在 `t08`，Python 不会自动去相邻文件夹找。**

你的目录是：

```text
ai-theory/
├── t06/
│   └── stable_softmax.py
└── t08/
    └── softmax_classifier_numpy.py
```

**改两处即可。**

### 1. 导入时写上目录名

```python
from t06.stable_softmax import stable_softmax
from t06.stable_softmax import cross_entropy_from_logits as stable_cross_entropy
```

`t06.stable_softmax` 就是“t06 目录里的 stable_softmax 模块”，这里省略 `.py`。

### 2. 从项目根目录运行

在你已经激活虚拟环境的终端里：

```bash
cd /home/xgf/code/system-learning/ai-theory
python -m t08.softmax_classifier_numpy
```

**`-m` 表示按模块名运行。** 此时项目根目录会加入模块搜索路径，Python 就能找到 `t06` 和 `t08`。[Python 官方说明](https://docs.python.org/3/using/cmdline.html#cmdoption-m)

先按这个方式运行，不用复制 T6 文件，也不用 `pip install stable_softmax`。

### **对，在刚才那种运行方式下，它能找到 `t06`，就是因为你的当前工作目录是 `ai-theory`。** 注释 1

你执行：

```bash
cd /home/xgf/code/system-learning/ai-theory
python -m t08.softmax_classifier_numpy
```

`python -m` 会把**当前工作目录加入 `sys.path`（模块搜索路径列表）**。随后：

```python
from t06.stable_softmax import stable_softmax
```

Python 就沿着下面这条路径寻找：

```text
模块搜索目录：/home/xgf/code/system-learning/ai-theory
    ↓ 找到 t06
t06/
    ↓ 找到 stable_softmax 模块
stable_softmax.py
    ↓ 取出其中的名称
stable_softmax 函数
```

**更准确地说：import 是相对于 `sys.path` 中的搜索目录寻找，不是固定相对于当前代码文件。** 当前工作目录只是通过这次 `-m` 启动方式，成为了搜索目录之一。

所以两种启动方式要区分：

| 启动方式 | 默认加入搜索路径的目录 |
|---|---|
| `python -m t08.softmax_classifier_numpy` | 当前工作目录，即这里的 `ai-theory` |
| `python t08/softmax_classifier_numpy.py` | 脚本所在目录，即这里的 `t08` |

这就是为什么我们这里选择**在根目录用 `-m` 运行**。[Python 官方说明](https://docs.python.org/3/using/cmdline.html#interface-options)
