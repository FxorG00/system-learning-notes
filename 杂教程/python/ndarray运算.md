**你现在会判断“结果有多大”，还缺的是：结果的每个位置，分别从 A、B 的哪里取数。广播的核心就在这里。**

先纠正一点：维度兼容要求是**长度相等（就是这个轴的数字相等），或者其中一个长度为 `1`**。缺失的维度按 `1` 看；`0` 不是通用匹配值，不能随便和 `3` 匹配。

## 看一个完整运算

```
A = [[10],
     [20]]       # shape (2, 1)

B = [[1, 2, 3]]  # shape (1, 3)
```

`A + B` 的结果 shape 是 `(2,3)`。那每个位置怎么算？

**长度为 `1` 的轴，总是取该轴上唯一的元素，也就是下标 `0`。**

所以：

```
结果位置    从 A 取什么    从 B 取什么    相加
(0,0)       A[0,0]=10     B[0,0]=1      11
(0,1)       A[0,0]=10     B[0,1]=2      12
(0,2)       A[0,0]=10     B[0,2]=3      13

(1,0)       A[1,0]=20     B[0,0]=1      21
(1,1)       A[1,0]=20     B[0,1]=2      22
(1,2)       A[1,0]=20     B[0,2]=3      23
```

得到：

```
[[11, 12, 13],
 [21, 22, 23]]
```

你可以把取数关系想成：

```
A 被重复使用为：       B 被重复使用为：
[[10, 10, 10],        [[1, 2, 3],
 [20, 20, 20]]         [1, 2, 3]]
```

这只是理解用的展开图，通常不需要真的复制出这些数组。

## 回到你的除法

```
A： (2,4,3)
B： (2,4,1)
```

计算结果位置 `(i,j,k)` 时：

- A 的各轴长度都与结果对应，取 `A[i,j,k]`。
- B 的最后一轴长度为 `1`，这一轴永远取下标 `0`，所以取 `B[i,j,0]`。

因此：

$$ C[i,j,k]=\frac{A[i,j,k]}{B[i,j,0]} $$

**记住这一条取数规则：轴长度相等，跟着结果坐标取；轴长度为 `1`，始终取下标 `0`。取完两个数，再执行你指定的加、减、乘、除。**

假设：

```text
A.shape = (1, 2, 3)
B.shape =    (2, 1)
```

**先右对齐，B 缺少的最前一轴按长度 `1` 看：**

```text
A： (1, 2, 3)
B： (1, 2, 1)
结果：(1, 2, 3)
```

用具体数值看 `A + B`：

```text
A = [[[10, 20, 30],
      [40, 50, 60]]]

B = [[1],
     [2]]
```

B 的两个数分别对应 A 的两行：

```text
第一行：[10, 20, 30] + 1 → [11, 21, 31]
第二行：[40, 50, 60] + 2 → [42, 52, 62]
```

结果：

```text
[[[11, 21, 31],
  [42, 52, 62]]]
```

**结果位置 `(i,j,k)`，取 `A[i,j,k]` 和 `B[j,0]` 运算。**

B 原本只有两个轴，所以访问时还是写 `B[j,0]`。补出的最前一轴只用于理解对齐，**并没有真的把 B 改成三维数组。**
