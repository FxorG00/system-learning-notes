**你现在遇到的几个词，其实是在说：一个 Python 文件怎样被别人使用，多个文件又怎样组织在一起。** 就用你的 T6、T8 来串。

## 1. Module：模块

**一个普通的 `.py` 文件，被 Python 导入使用时，就是一个模块。**

比如：

```text
t06/stable_softmax.py
```

文件里面定义了函数：

```python
def stable_softmax(...):
    ...

def cross_entropy_from_logits(...):
    ...
```

这里有三个不同的对象：

```text
stable_softmax.py              → 文件
t06.stable_softmax             → 模块名
模块里面的 stable_softmax     → 函数
```

因此：

```python
from t06.stable_softmax import stable_softmax
```

意思是：

> 找到 `t06.stable_softmax` 这个模块，从里面取出名为 `stable_softmax` 的对象。

模块和函数恰好同名，容易看混；它们完全可以起不同名字。

## 2. Package：包

**当代码多了，用一个目录把多个模块组织起来，这个组织单位就是包。**

典型结构是：

```text
t06/
├── __init__.py
├── stable_softmax.py
└── sampling.py
```

其中：

| 名称 | 对应角色 |
|---|---|
| `t06` | 包 |
| `t06.stable_softmax` | 包里的模块 |
| `t06.sampling` | 包里的另一个模块 |

**点号表示逐层进入 Python 的模块组织结构：**

```python
import t06.stable_softmax
```

可以理解为先找到 `t06`，再找到其中的 `stable_softmax`。

### `__init__.py` 是干什么的？

它把目录标识为一个**普通包**；第一次导入这个包时，Python 会执行其中的代码。文件可以为空。

Python 3 还支持 **namespace package（命名空间包）**：满足条件时，没有 `__init__.py` 的目录也能作为包使用。你现在的 `t06` 就可以采用这种形式，所以刚才没有要求你补这个文件。

当前先认识这两种形式即可，不需要展开命名空间包的高级用法。

## 3. Import：导入

**导入就是找到模块、加载它，并把需要的名称放进当前代码。**

下面两种写法的区别主要是“当前代码里得到什么名字”：

```python
import numpy as np

np.array([1, 2, 3])
```

当前得到模块的别名 `np`，通过它访问 `array`。

```python
from numpy import array

array([1, 2, 3])
```

当前直接得到 `array` 这个名称。

对应你的代码：

```python
from t06.stable_softmax import (
    cross_entropy_from_logits as stable_cross_entropy,
)
```

就是把模块里的函数取出来，**在当前文件中改叫 `stable_cross_entropy`**。

还有一种**相对导入**：

```python
from .sampling import draw
```

这里的 `.` 表示当前包；它依据的是**包的位置关系**，不是终端当前目录。

## 4. Library：库

**库是“一组供别人使用的功能”的统称，可以包含很多包和模块。**

比如 NumPy 是一个数值计算库，你通过：

```python
import numpy as np
```

使用它提供的数组与计算功能。

“库”主要描述用途，不像“模块”“包”那样严格对应某一级文件组织。

## 5. Script：脚本

**当一个文件被你拿来启动执行任务时，我们通常称它为脚本。**

同一个文件可以有两种用法：

```text
被其他代码 import → 作为模块使用
被你启动运行      → 作为程序入口使用
```

这就是你常见到下面这段代码的原因：

```python
if __name__ == "__main__":
    main()
```

**直接运行时执行 main；被 import 时保留函数供调用，不自动启动 main。**

不过，导入模块仍会执行它的其他顶层代码；这个判断只保护里面包住的部分。
