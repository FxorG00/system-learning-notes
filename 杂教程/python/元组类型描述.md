## 类型描述

> 其实就是类似 c++ 里 vector<int>

**你记得没错：创建 tuple（元组）通常写圆括号。这里的方括号是在写“类型说明”，不是创建 tuple。**

先把两个场景分开。

**1. 创建实际数据**

```python
a = [1, 2]       # list：列表
b = (1, 2)       # tuple：元组
c = {"x": 1}     # dict：字典，键 → 值
d = {1, 2}       # set：集合
```

补两个细节：空花括号 `{}` 是空字典，空集合写 `set()`；单元素元组写 `(1,)`，逗号很重要，`(1)` 只是数字 1。

**2. 描述数据的类型**

```python
tuple[np.ndarray, np.ndarray]
```

这段的意思是：

> **一个包含两个元素的 tuple，第一个是 ndarray，第二个也是 ndarray。**

类型名后面的 `[...]` 用来补充“里面装什么类型”。类似地：

```python
list[int]          # 元素为整数的列表
dict[str, int]    # key 为字符串、value 为整数的字典
tuple[int, str]   # 两个元素的元组：整数、字符串
```

回到你的函数：

```python
def make_dataset(seed: int = 2026) -> tuple[np.ndarray, np.ndarray]:
    ...
```

箭头后面说明：**返回一个二元素元组，分别装 features 数组和 labels 数组。**

实际返回时可以写：

```python
return features, labels
```

它等价于：

```python
return (features, labels)
```

调用时再拆开：

```python
features, labels = make_dataset()
```

**一句话：`(features, labels)` 是实际的元组；`tuple[np.ndarray, np.ndarray]` 是对这个元组的类型描述。**

## 区分开类型描述与创建对象

**因为这一行是在描述“列表的类型”，没有创建一个实际的列表：**

```python
points = list[tuple[np.float64, np.float64]]
```

你把类型描述赋给了 `points`，所以它不是能够存放数据的 list 对象。

应该把**类型注解**和**创建列表**分开：

```python
points: list[tuple[np.float64, np.float64]] = []
```

读法是：

```text
points          变量名
: 后面的内容     类型注解：列表里放二元素 tuple
= []            创建一个真正的空列表，赋给 points
```

现在就能追加：

```python
points.append((np.float64(1.2), np.float64(3.4)))
```

**`append` 接收一个对象。** 这里传进去的一个对象，就是整个 `(x, y)` 元组。

如果暂时不写类型注解，直接这样也完全可以：

```python
points = []
points.append((1.2, 3.4))
```

**记住区别：`list[...]` 描述类型；`[]` 创建列表。类型注解也不会自动帮你创建或转换元素。**
