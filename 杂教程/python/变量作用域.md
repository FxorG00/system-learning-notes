好。我们就从你刚才的疑问出发：**Python 怎样决定一个变量名属于哪里？在里面给它赋值，会不会影响外面？**

先看你刚才的代码：

```python
def train():
    saved_state = None

    for i in range(3):
        saved_state = i

    print(saved_state)  # 2
```

为什么循环里面改了 `saved_state`，循环外面能看到？

因为 **Python 的 `for` 不会像函数那样创建新的局部作用域**。这就是我们要先抓住的一条规则。

---

# 1. 变量名可以理解成“指向对象的名字”

先看一个简单例子：

```python
value = 10
```

你可以理解为：

```text
名字 value
    ↓
整数对象 10
```

然后：

```python
value = 20
```

现在变成：

```text
名字 value
    ↓
整数对象 20
```

这叫**重新绑定**：让 `value` 这个名字指向另一个对象。

我们接下来讨论的“作用域”，就是：

> **程序在哪个范围里寻找这个名字？给这个名字赋值时，又会影响哪个范围？**

---

# 2. 函数里面创建的变量，通常只属于这个函数

```python
def train():
    epoch = 10
    print(epoch)

train()
print(epoch)
```

运行时：

```text
10
NameError: name 'epoch' is not defined
```

原因是：

```python
epoch = 10
```

写在 `train()` 里面，因此这里的 `epoch` 是 `train()` 的**局部变量**。

它能在函数内部使用：

```text
train 函数范围内 → 能找到 epoch
```

但函数外部不能直接通过这个名字找到它：

```text
train 函数范围外 → 找不到局部变量 epoch
```

函数参数也是局部变量：

```python
def train(steps):
    print(steps)

train(2000)   # 2000
print(steps)  # NameError
```

`steps` 只属于这次 `train()` 调用。

## 函数结束后怎样把结果交出去？

用 `return`：

```python
def train():
    epoch = 10
    return epoch

result = train()

print(result)  # 10
```

这和你在 T13 中返回 `history` 是同一个道理：

```text
函数内部产生结果
        ↓
return
        ↓
调用者用自己的变量接住
```

# 3. `for` 和 `if` 不会创建新的函数作用域

看你熟悉的训练循环：

```python
def train():
    saved_state = None

    for epoch in range(3):
        saved_state = epoch

    print(saved_state)
```

输出：

```text
2
```

虽然 `saved_state = epoch` 写在 `for` 里面，但它仍然属于 `train()`：

```text
train() 的局部作用域
├── saved_state
└── epoch

for 循环
→ 使用这两个名字
→ 不另外创建一个函数作用域
```

`if` 也是一样：

```python
def example():
    if True:
        result = 42

    print(result)  # 42
```

`try`、`while` 也是如此。

但要注意：**作用域没有新建，不代表代码块一定执行过。**

```python
def example():
    if False:
        result = 42

    print(result)  # 出错：result 从来没有被赋值
```

同理，如果 `for` 一次都没执行，循环里才赋值的变量也可能还不存在。

---

# 4. 函数可以读取外面的变量

先看：

```python
learning_rate = 0.01

def show_learning_rate():
    print(learning_rate)

show_learning_rate()
```

输出：

```text
0.01
```

为什么函数里面没有定义 `learning_rate`，却能读到？

因为 Python 找名字时，会先看当前函数内部；找不到，再往外找：

```text
show_learning_rate 里面有 learning_rate 吗？
    ↓ 没有
模块外层有 learning_rate 吗？
    ↓ 有
使用外层的 0.01
```

这里的“模块”可以先理解成当前这个 `.py` 文件对应的命名空间。

顶层定义的变量，例如：

```python
learning_rate = 0.01
```

通常就叫这个模块的**全局变量**。

---

# 5. 但在函数里赋值，不会自动修改全局变量

现在稍微改一下：

```python
learning_rate = 0.01

def change_learning_rate():
    learning_rate = 0.1
    print("函数内：", learning_rate)

change_learning_rate()
print("函数外：", learning_rate)
```

输出：

```text
函数内： 0.1
函数外： 0.01
```

原因是：

```python
learning_rate = 0.1
```

这次赋值发生在函数内部。没有额外声明时，Python 把它当成函数的局部变量。

所以实际上有两个不同的名字位置：

```text
模块作用域：
learning_rate → 0.01

函数局部作用域：
learning_rate → 0.1
```

它们恰好同名，但不是同一个变量位置。

## 一个常见报错：`UnboundLocalError`

```python
count = 0

def increase():
    count = count + 1
```

调用：

```python
increase()
```

会报：

```text
UnboundLocalError
```

你可能会想：“外面不是有 `count = 0` 吗？”

问题在于函数里有赋值：

```python
count = ...
```

因此 Python 把这个函数中的 `count` 视为局部变量。执行右边的：

```python
count + 1
```

时，这个局部 `count` 还没有得到值，于是报错。

# 6. `global`：让函数给模块级名字重新赋值

如果你确实想让函数修改模块里的 `count`：

```python
count = 0

def increase():
    global count
    count = count + 1

increase()
increase()

print(count)  # 2
```

`global count` 告诉 Python：

> **这个函数中对 `count` 的读取和赋值，使用当前模块里的 `count`。**

因此：

```python
count = count + 1
```

修改的是外面的全局名字。

回到你刚才最开始的写法：

```python
saved_state = None

def save_model(model):
    global saved_state
    saved_state = copy.deepcopy(model.state_dict())
```

这里的 `saved_state` 确实指向模块里的变量。

但如果只是为了让调用者拿到结果，通常返回值更直观：

```python
def save_model(model):
    return copy.deepcopy(model.state_dict())

saved_state = save_model(model)
```

这样函数依赖和结果都能从调用处看出来。

**注意：**`global` 指的是当前模块里的全局名字，不是“整个 Python 程序所有文件共享的同名变量”。

# 7. 函数里面还可以再定义函数

你的 T13 代码就有这种结构：

```python
def train_and_measure():
    history = []

    def record(epoch):
        history.append(epoch)

    record(0)
    record(20)

    print(history)
```

输出：

```text
[0, 20]
```

这里有两层函数：

```text
train_and_measure()
├── history
└── record()
```

`record()` 里没有定义 `history`，所以它会向外一层找，在 `train_and_measure()` 里找到它。

这就是为什么你的 `record()` 能使用外面的：

```python
history.append(...)
```

# 8. `nonlocal`：让内层函数修改外层函数的变量名

现在假设你想把“保存最佳模型”的动作也放进 `record()`：

```python
def train_and_measure():
    saved_state = None

    def record():
        saved_state = "第一个快照"

    record()
    print(saved_state)
```

你可能期待打印：

```text
第一个快照
```

但实际上打印：

```text
None
```

因为内层的：

```python
saved_state = "第一个快照"
```

默认创建了 `record()` 自己的局部变量。

此时需要 `nonlocal`：

```python
def train_and_measure():
    saved_state = None

    def record():
        nonlocal saved_state
        saved_state = "第一个快照"

    record()
    print(saved_state)  # 第一个快照
```

`nonlocal saved_state` 的意思是：

> **这个名字不属于当前内层函数；去外层函数作用域里找到它，并修改那里的绑定。**

## `global` 和 `nonlocal` 的区别

```text
global
→ 使用当前模块(这个.py)顶层的变量

nonlocal
→ 使用外层函数中已有的变量
```

放在一起看：

```python
message = "模块里的变量"

def outer():
    saved_state = "外层函数里的变量"

    def inner():
        global message
        nonlocal saved_state

        message = "修改模块变量"
        saved_state = "修改外层函数变量"

    inner()

    print(saved_state)  # 修改外层函数变量

outer()

print(message)  # 修改模块变量
```

注意：`nonlocal` 必须能在某个外层函数作用域里找到这个名字；它不是用来找模块全局变量的。

# 9. 为什么 `history.append()` 不需要 `nonlocal`？

这点很容易和刚才的 `saved_state = ...` 混起来。

你写的是：

```python
def train_and_measure():
    history = []

    def record():
        history.append({"epoch": 0})

    record()
    print(history)
```

不需要 `nonlocal`，因为：

```python
history.append(...)
```

做的是：

> 找到外层的 `history`，然后修改它指向的那个 list。

它**没有给名字 `history` 重新赋值**。

看图：

```text
外层名字 history
       ↓
      list
       ↓
record() 找到这个 list
       ↓
append：给同一个 list 增加一项
```

但如果你这样写：

```python
def record():
    history = []
```

那就是给 `history` **重新赋值**。默认会变成 `record()` 里的局部名字，不会把外层的 `history` 换掉。

对照一下：

```python
history.append(row)  # 修改已有 list

history = []         # 给名字重新绑定一个 list
```

**是否要用 `nonlocal`，关键看你是否要在内层函数里重新绑定外层的名字。**

# 10. Python 找变量的顺序：LEGB

前面这些例子可以总结成一条查找顺序：

```text
L：Local
   当前函数内部

E：Enclosing
   外层函数内部

G：Global
   当前模块顶层

B：Built-in
   Python 内置名字
```

比如：

```python
name = "global"

def outer():
    name = "outer"

    def inner():
        name = "inner"
        print(name)

    inner()

outer()
```

输出：

```text
inner
```

因为 `inner()` 自己的局部作用域里就找到了 `name`。

如果删掉内层的赋值：

```python
name = "global"

def outer():
    name = "outer"

    def inner():
        print(name)

    inner()

outer()
```

输出：

```text
outer
```

Python 从当前函数找不到，就到外层函数找到 `name`。

如果外层函数也没有，再去模块全局找；最后才考虑 Python 的内置名字，例如 `print`、`len`。

你不需要死背字母，先记住：

> **读取名字时，先从近处找；找不到再向外找。**

但赋值有我们刚才讲的规则：**函数内直接赋值，默认绑定到当前函数的局部变量**，除非声明了 `global` 或 `nonlocal`。

# 11. 最后回到你的 T13 代码

你目前的结构大致是：

```python
def train_and_measure(...):
    history = []
    saved_model_state_dict = None

    def record(epoch):
        history.append(...)

    record(0)

    for i in range(steps):
        ...
        if ...:
            saved_model_state_dict = save_model(model)

    return history, saved_model_state_dict
```

逐个看：

```text
history
→ train_and_measure 的局部变量

record()
→ 可以读取外层的 history
→ append 修改同一个 list，不需要 nonlocal

for 循环里的 saved_model_state_dict = ...
→ 仍在 train_and_measure 的作用域里
→ 不需要 global，也不需要 nonlocal

return
→ 把训练记录和最佳状态交给调用者
```

如果以后你把保存动作移进 `record()`：

```python
def train_and_measure(...):
    saved_model_state_dict = None

    def record(epoch):
        nonlocal saved_model_state_dict
        saved_model_state_dict = save_model(model)
```

这时候才需要 `nonlocal`，因为你要在**内层函数**里重新给外层函数的变量赋值。

## 收个口

| 你在做什么 | 通常需要什么？ |
|---|---|
| 在 `for` / `if` 里给同一函数的变量赋值 | 直接赋值 |
| 内层函数读取外层变量 | 直接读取 |
| 内层函数调用外层 list 的 `append()` | 直接调用 |
| 内层函数重新给外层函数变量赋值 | `nonlocal` |
| 函数重新给模块级全局变量赋值 | `global` |
| 把函数结果交给调用者 | 优先考虑 `return` |

你刚才的情况属于第一行：**`for` 不是新函数，所以直接赋值就可以。**
