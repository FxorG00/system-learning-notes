用 **`raise` 抛异常**，`ValueError` 注意大小写：

```python
def check_epsilon(epsilon):
    if epsilon <= 0:
        raise ValueError("epsilon must be positive")

check_epsilon(-1)
```

运行会报：

```text
ValueError: epsilon must be positive
```

`ValueError` 通常表示：**参数的类型合适，但值不符合要求**，比如这里传了数字，却不是正数。

用 `try / except` 可以捕获：

```python
try:
    check_epsilon(-1)
except ValueError as error:
    print(error)  # epsilon must be positive
```

对应 C++：`raise` 类似 `throw`，`except` 类似 `catch`。
