﻿﻿# 模板与泛型编程教程

> 这份教程专门补 C++ 模板与泛型编程。目标不是把模板讲成“玄学”，而是让你能看懂选择题、能写代码题里常见的函数模板和类模板。

## 0. 先记住三句话

1. 模板是“写一份代码，给很多类型用”。
2. 模板不是运行时多态，模板主要发生在编译期。
3. 模板代码只有在被具体类型使用时，编译器才会生成对应版本。

比如你想写一个交换函数：

```cpp
void swapInt(int& a, int& b) {
    int t = a;
    a = b;
    b = t;
}

void swapDouble(double& a, double& b) {
    double t = a;
    a = b;
    b = t;
}
```

这两个函数逻辑一模一样，只是类型不同。模板就是把类型抽出来：

```cpp
template <typename T>
void mySwap(T& a, T& b) {
    T t = a;
    a = b;
    b = t;
}
```

这里的 `T` 不是一个真实类型，而是“类型占位符”。调用时：

```cpp
int a = 1, b = 2;
mySwap(a, b);        // T 被推导为 int

double x = 1.5, y = 2.5;
mySwap(x, y);        // T 被推导为 double
```

## 1. 泛型编程是什么

泛型编程的核心是：算法逻辑不依赖某个具体类型。

比如“取较大值”这个动作，对 `int`、`double`、`string` 都可能成立：

```cpp
template <typename T>
T maxValue(T a, T b) {
    return a > b ? a : b;
}
```

只要 `T` 类型支持 `>` 比较和复制返回，这个模板就能用。

### 模板和多态的区别

| 对比 | 模板 | 虚函数多态 |
|---|---|---|
| 发生时间 | 编译期 | 运行期 |
| 常见语法 | `template <typename T>` | `virtual` / `override` |
| 目的 | 让一份代码适配多种类型 | 通过基类指针/引用调用派生类版本 |
| 典型例子 | `vector<int>`、`sort` | `Base* p = new Derived; p->f();` |

选择题高频坑：泛型编程不是运行时动态多态。模板更接近“编译器帮你按类型生成代码”。

## 2. 函数模板

### 2.1 基本语法

```cpp
template <typename T>
返回类型 函数名(参数列表) {
    函数体
}
```

例子：

```cpp
template <typename T>
T add(T a, T b) {
    return a + b;
}
```

调用：

```cpp
cout << add(1, 2);        // T = int
cout << add(1.5, 2.5);    // T = double
```

### 2.2 `typename` 和 `class`

在模板参数列表中，下面两种写法基本等价：

```cpp
template <typename T>
T f(T x) { return x; }

template <class T>
T g(T x) { return x; }
```

课程里你可以先记：声明类型模板参数时，`typename` 和 `class` 基本都能用。

推荐用 `typename`，因为它更直观：这里需要的是“一个类型”。

### 2.3 多个模板参数

如果两个参数类型可以不同，就要写两个模板参数：

```cpp
template <typename T, typename U>
void printPair(T a, U b) {
    cout << a << " " << b << endl;
}
```

调用：

```cpp
printPair(1, 2.5);      // T = int, U = double
printPair("age", 18);   // T = const char*, U = int
```

如果你只写一个 `T`：

```cpp
template <typename T>
T foo(T a, T b) {
    return a;
}
```

那么两个参数都要推导成同一个类型。

```cpp
foo(1, 2);      // 可以，T = int
foo(1.0, 2.0);  // 可以，T = double
foo(1, 2.5);    // 容易出错：一个像 int，一个像 double
```

这是选择题高频点：同一个 `T` 要推导一致。

如果想强行指定：

```cpp
foo<double>(1, 2.5);    // 指定 T = double，1 可转成 double
```

## 3. 模板参数推导

### 3.1 编译器怎么推导

看这个模板：

```cpp
template <typename T>
void print(T x) {
    cout << x << endl;
}
```

调用：

```cpp
print(10);       // T = int
print(3.14);     // T = double
print('A');      // T = char
```

编译器根据实参类型推导 `T`。

### 3.2 推导失败的常见情况

同一个模板参数得到两个不同答案：

```cpp
template <typename T>
T maxValue(T a, T b) {
    return a > b ? a : b;
}

maxValue(1, 2);      // T = int
maxValue(1.2, 2.3);  // T = double
maxValue(1, 2.3);    // T 推导冲突
```

解决方法：

```cpp
maxValue<double>(1, 2.3);
```

或者把模板写成两个类型：

```cpp
template <typename T, typename U>
auto maxValue(T a, U b) {
    return a > b ? a : b;
}
```

这里 `auto` 返回类型让编译器根据返回表达式推导。

### 3.3 引用参数与模板

交换函数一般要用引用：

```cpp
template <typename T>
void mySwap(T& a, T& b) {
    T t = a;
    a = b;
    b = t;
}
```

因为如果不用引用：

```cpp
template <typename T>
void badSwap(T a, T b) {
    T t = a;
    a = b;
    b = t;
}
```

这只是交换副本，不会改变外面的变量。

### 3.4 `const T&` 很常用

如果只是读取参数，不想复制大对象，常写：

```cpp
template <typename T>
void printValue(const T& x) {
    cout << x << endl;
}
```

好处：

- `const`：函数不会修改实参。
- `&`：避免复制大对象，比如 `string`、`vector`、自定义类。
- `const T&` 可以绑定临时对象。

## 4. 类模板

函数模板是“函数泛型”，类模板是“类泛型”。

### 4.1 基本语法

```cpp
template <typename T>
class Box {
private:
    T value;

public:
    Box(T v) : value(v) {}

    T get() const {
        return value;
    }
};
```

使用时必须给出具体类型：

```cpp
Box<int> a(10);
Box<string> b("hello");

cout << a.get() << endl;
cout << b.get() << endl;
```

注意：`Box` 只是模板，不是具体类型；`Box<int>` 才是具体类型。

### 4.2 类模板可以有多个参数

```cpp
template <typename K, typename V>
class Pair {
private:
    K key;
    V value;

public:
    Pair(K k, V v) : key(k), value(v) {}

    K getKey() const { return key; }
    V getValue() const { return value; }
};
```

使用：

```cpp
Pair<string, int> p("Alice", 90);
```

### 4.3 类模板成员函数写在类外

这是选择题和代码题都容易考的语法。

错误直觉：

```cpp
void Box<T>::set(T v) { ... }   // 少了 template <typename T>
```

正确写法：

```cpp
template <typename T>
class Box {
private:
    T value;

public:
    Box(T v);
    void set(T v);
    T get() const;
};

template <typename T>
Box<T>::Box(T v) : value(v) {}

template <typename T>
void Box<T>::set(T v) {
    value = v;
}

template <typename T>
T Box<T>::get() const {
    return value;
}
```

类外实现模板成员函数时，记住两件事：

1. 前面要再写一遍 `template <typename T>`。
2. 类名要写成 `Box<T>`，不是单独的 `Box`。

## 5. 非类型模板参数

前面 `T` 是类型参数。模板参数也可以是值，这叫非类型模板参数。

```cpp
template <typename T, int N>
class Array {
private:
    T data[N];

public:
    int size() const {
        return N;
    }
};
```

使用：

```cpp
Array<int, 5> a;
Array<double, 10> b;
```

这里的 `N` 是编译期常量。

### 5.1 必须是编译期常量

可以：

```cpp
const int N = 5;
Array<int, N> a;
```

更推荐：

```cpp
constexpr int N = 5;
Array<int, N> a;
```

不可以：

```cpp
int n;
cin >> n;
Array<int, n> a;   // 错误：n 是运行期变量
```

选择题里看到：

```cpp
template <int Size>
class Buffer {
    int data[Size];
};

int n;
cin >> n;
Buffer<n> b;
```

应判断：编译失败，因为 `n` 不是编译期常量。

### 5.2 `Array<int, 5>` 和 `Array<int, 6>` 是不同类型

```cpp
Array<int, 5> a;
Array<int, 6> b;
```

它们不是同一个类型，因为模板实参不同。

下面这两个通常是同一类型：

```cpp
Array<int, 2 + 3> a;
Array<int, 5> b;
```

因为 `2 + 3` 是编译期常量表达式，结果就是 5。

## 6. 数组和模板：最常考的坑

### 6.1 普通数组形参会退化

```cpp
template <typename T, int N>
void f(T arr[N]) {
}
```

你可能以为 `N` 能推导出来，但不行。

函数参数里的数组会退化成指针，`T arr[N]` 近似变成：

```cpp
T* arr
```

所以长度 `N` 丢了。

### 6.2 用数组引用保留长度

正确写法：

```cpp
template <typename T, int N>
void getLength(T (&arr)[N]) {
    cout << N << endl;
}
```

使用：

```cpp
int a[10];
getLength(a);      // T = int, N = 10
```

为什么要写 `(&arr)[N]`？

- `arr` 是数组的引用。
- 引用不会让数组退化成指针。
- 所以编译器能看到数组长度。

### 6.3 二维数组也可以推导

```cpp
template <typename T, int R, int C>
void processMatrix(T (&matrix)[R][C]) {
    cout << R << " " << C << endl;
}

double mat[3][5];
processMatrix(mat);    // T = double, R = 3, C = 5
```

## 7. 模板重载、特化、普通函数优先级

这部分选择题很爱考。先不用钻太深，掌握常见规则就够。

### 7.1 函数模板可以重载

```cpp
template <typename T>
void foo(T x) {
    cout << "A";
}

template <typename T>
void foo(T* x) {
    cout << "B";
}
```

调用：

```cpp
int n = 10;
foo(n);     // A，参数是 int
foo(&n);    // B，参数是 int*
```

第二个模板更适合指针参数。

### 7.2 函数模板全特化

主模板：

```cpp
template <typename T>
void print(T x) {
    cout << "general";
}
```

给 `int` 写一个特化版本：

```cpp
template <>
void print<int>(int x) {
    cout << "int";
}
```

也可以写成：

```cpp
template <>
void print(int x) {
    cout << "int";
}
```

重点：全特化前面写 `template <>`，尖括号里是空的。

### 7.3 普通函数和模板都匹配时，普通函数优先

```cpp
template <typename T>
void print(T x) {
    cout << 1;
}

template <>
void print(int x) {
    cout << 2;
}

void print(int x) {
    cout << 3;
}

int main() {
    print(10);
}
```

输出通常是：

```text
3
```

因为有一个普通的非模板函数 `void print(int)` 完美匹配，优先于模板。

这题的判断抓手：

1. 先看有没有普通函数完美匹配。
2. 再看函数模板重载。
3. 最后才考虑特化版本。

## 8. 类模板特化

类模板也可以特化。比如通用版本：

```cpp
template <typename T>
class Printer {
public:
    void print(T x) {
        cout << x << endl;
    }
};
```

如果 `string` 要特殊处理：

```cpp
template <>
class Printer<string> {
public:
    void print(const string& s) {
        cout << "\"" << s << "\"" << endl;
    }
};
```

语法要点：

```cpp
template <>
class 模板名<具体类型> {
    ...
};
```

特化版本可以和主模板有不同成员。选择题里如果说“特化版本必须和主模板成员完全一样”，这是错的。

## 9. `typename` 的第二个用法

多数初学阶段，你只需要知道：

```cpp
template <typename T>
```

这里的 `typename` 表示 `T` 是类型参数。

但模板里还有一种用法：

```cpp
template <typename Container>
void f(Container c) {
    typename Container::iterator it = c.begin();
}
```

这里 `Container::iterator` 依赖模板参数 `Container`。编译器一开始不知道它到底是不是类型，所以要加 `typename` 告诉编译器：

```cpp
typename Container::iterator
```

意思是：请把 `Container::iterator` 当作类型。

这属于选择题可能出现、代码题较少手写的点。先会判断即可。

## 10. 为什么模板常写在头文件里

普通函数可以这样：

```cpp
// add.h
int add(int a, int b);

// add.cpp
int add(int a, int b) {
    return a + b;
}
```

因为普通函数在编译 `.cpp` 时就能生成机器代码。

模板不同：

```cpp
template <typename T>
T add(T a, T b) {
    return a + b;
}
```

编译器不知道你以后会用：

```cpp
add<int>
add<double>
add<string>
```

哪个版本。所以模板通常要让“使用它的地方”看见完整定义。

因此模板经常写在 `.h` / `.hpp` 里：

```cpp
// my_template.hpp
template <typename T>
T add(T a, T b) {
    return a + b;
}
```

选择题高频说法：模板声明和实现通常放在同一个头文件中，因为模板实例化需要看到完整定义。

## 11. STL 就是大量模板

你平时用的 STL 容器几乎都是类模板。

```cpp
vector<int> vi;
vector<double> vd;
vector<string> vs;
```

`vector<T>` 是模板，`vector<int>` 是具体类型。

```cpp
map<string, int> score;
set<int> nums;
priority_queue<int> pq;
```

这些尖括号里的内容就是模板实参。

所以学模板不是额外知识，它解释了你为什么能写：

```cpp
vector<int>
vector<string>
map<string, int>
```

## 12. 代码题怎么写模板

代码题里遇到模板，按这个流程来。

### 第一步：找重复类型

如果题目让你写一个容器、数组、栈、队列、Pair、Box，而且元素类型不固定，就考虑类模板。

```cpp
template <typename T>
class Stack {
private:
    vector<T> data;

public:
    void push(const T& x) {
        data.push_back(x);
    }

    void pop() {
        data.pop_back();
    }

    T top() const {
        return data.back();
    }

    bool empty() const {
        return data.empty();
    }
};
```

使用：

```cpp
Stack<int> s1;
Stack<string> s2;
```

### 第二步：不要把类型写死

错误：

```cpp
template <typename T>
class Box {
private:
    int value;       // 写死 int，模板失去意义
};
```

正确：

```cpp
template <typename T>
class Box {
private:
    T value;
};
```

### 第三步：参数尽量用 `const T&`

```cpp
template <typename T>
class Box {
private:
    T value;

public:
    Box(const T& v) : value(v) {}

    void set(const T& v) {
        value = v;
    }

    const T& get() const {
        return value;
    }
};
```

为什么 `get` 返回 `const T&`？

- 避免复制。
- 不允许调用者直接改内部值。

如果题目要求返回值而不是引用，按题目签名来，不要擅自改。

### 第四步：类外实现别忘模板头

```cpp
template <typename T>
class Stack {
public:
    void push(const T& x);
};

template <typename T>
void Stack<T>::push(const T& x) {
    // ...
}
```

这个语法是模板代码题最常见扣分点。

## 13. 常见错误速查

| 错误现象 | 常见原因 | 正确理解 |
|---|---|---|
| `foo(1, 2.5)` 编译失败 | 同一个 `T` 推导出 `int` 和 `double` | 显式指定 `foo<double>`，或写两个模板参数 |
| `Buffer<n>` 编译失败 | `n` 是运行期变量 | 非类型模板实参必须是编译期常量 |
| 类模板成员函数类外定义报错 | 忘记 `template <typename T>` 或 `Class<T>::` | 类外实现要同时写模板头和 `类名<T>` |
| 数组长度 `N` 推导不出来 | 数组形参退化为指针 | 用 `T (&arr)[N]` 数组引用 |
| 模板放 `.cpp` 后链接错误 | 使用处看不到模板定义 | 模板通常放头文件 |
| `Box b(1)` 报错 | 旧标准下类模板不能自动推导模板实参 | 写 `Box<int> b(1)` |
| 模板里写死 `int` | 没有真正泛型化 | 用 `T` 替换元素类型 |
| `typename Container::iterator` 少了 `typename` | 依赖类型没有告诉编译器 | 从属依赖类型前加 `typename` |

## 14. 选择题判断口诀

### 14.1 看模板参数

```cpp
template <typename T, int N>
```

这里：

- `T` 是类型参数。
- `N` 是非类型参数，必须是编译期常量。

### 14.2 看是不是同一个 `T`

```cpp
template <typename T>
void f(T a, T b);
```

两个参数要推导成同一种类型。

```cpp
f(1, 2);      // 可以
f(1, 2.5);    // 可能推导失败
```

### 14.3 看数组有没有退化

```cpp
void f(T arr[N]);       // 退化，长度不可靠
void g(T (&arr)[N]);    // 不退化，可推导长度
```

### 14.4 看类外定义有没有模板头

正确模式：

```cpp
template <typename T>
返回类型 类名<T>::函数名(参数) {
}
```

### 14.5 看普通函数是否优先

如果普通函数和模板都完美匹配，一般普通函数优先。

## 15. 小练习

### 练习 1：判断 `T`

```cpp
template <typename T>
void f(T x) {}

f(10);
f(3.14);
f('A');
```

答案：

- `f(10)`：`T = int`
- `f(3.14)`：`T = double`
- `f('A')`：`T = char`

### 练习 2：是否能编译

```cpp
template <typename T>
T maxValue(T a, T b) {
    return a > b ? a : b;
}

maxValue(1, 2.5);
```

答案：通常不能直接通过模板参数推导，因为同一个 `T` 同时被推成 `int` 和 `double`。

修改：

```cpp
maxValue<double>(1, 2.5);
```

### 练习 3：数组长度推导

```cpp
template <typename T, int N>
void len(T (&arr)[N]) {
    cout << N;
}

int a[8];
len(a);
```

答案：输出 `8`，`T = int`，`N = 8`。

### 练习 4：类外实现

补全 `set` 的类外实现：

```cpp
template <typename T>
class Box {
private:
    T value;

public:
    void set(T v);
};
```

答案：

```cpp
template <typename T>
void Box<T>::set(T v) {
    value = v;
}
```

### 练习 5：非类型模板参数

```cpp
template <int N>
class Buffer {};

int n;
cin >> n;
Buffer<n> b;
```

答案：错误。`n` 是运行期变量，不是编译期常量。

## 16. 一页速记

- 模板 = 写一份代码，给多种类型用。
- `template <typename T>`：`T` 是类型占位符。
- 函数模板可以让编译器根据实参推导类型。
- 同一个 `T` 要推导一致：`f(T, T)` 不适合直接传 `int` 和 `double` 混合参数。
- 类模板使用时要写具体类型：`Box<int>`、`vector<string>`。
- 类模板成员函数类外定义：`template <typename T>` + `Class<T>::func`。
- 非类型模板参数必须是编译期常量。
- 数组想保留长度，用 `T (&arr)[N]`。
- 全特化写 `template <>`。
- 普通函数和模板都完美匹配时，普通函数通常优先。
- 模板定义通常放头文件，因为实例化时需要看到完整实现。
- STL 容器基本都是模板：`vector<T>`、`map<K, V>`、`set<T>`。

## 17. 最推荐的学习顺序

1. 先会写函数模板：`maxValue`、`mySwap`。
2. 再会写类模板：`Box<T>`、`Stack<T>`。
3. 再理解模板参数推导：为什么 `foo(1, 2.5)` 不行。
4. 再学非类型模板参数：`Array<T, N>`。
5. 最后看特化、普通函数优先级、`typename` 依赖类型。

你如果只想先应付课程题，优先掌握前 4 步就够用了。
