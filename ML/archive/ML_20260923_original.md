## 6. 线性回归

线性回归模型（Linear Regression Model）是监督学习中最基础也最经典的算法，专门用来解决我们之前探讨过的**回归问题**（即预测连续数值）。

你可以把它想象成在图表上“找规律”。假设我们在坐标系中标出了一堆数据点，横轴 $x$ 是房屋面积，纵轴 $y$ 是房屋真实售价。线性回归的终极目标，就是在这堆密密麻麻的点中间，画出一条**最贴合这些数据分布的直线**。

这条直线的数学表达就是你在中学代数里学过的一次函数：


$$f_{w,b}(x) = wx + b$$

在机器学习的语境下，我们赋予了这些字母全新的含义：

* $x$：**输入特征 (Feature)**，即我们已知的信息，比如房屋的面积。
* $w$：**权重 (Weight)**，代表直线的斜率。它决定了 $x$ 的变化对预测结果有多大影响（比如面积每增加一平米，价格会涨多少）。
* $b$：**偏差 (Bias)**，代表直线在纵轴上的截距。可以粗略理解为不受面积影响的“基础底价”。
* $f_{w,b}(x)$ 或简写为 $\hat{y}$：模型的**预测输出 (Prediction)**，即模型根据当前输入的面积算出的预估房价。

**机器在这里到底在“学习”什么？**
答案就是 $w$ 和 $b$ 这两个参数。算法在最初完全是瞎猜，随便画一条线。然后它会观察这条线和真实数据点之间的误差，不断去调整直线的倾斜度 ($w$) 和上下位置 ($b$)，直到这条直线尽可能紧密地穿过所有已知的历史数据点。一旦找到了那组最完美的 $w$ 和 $b$，模型就训练完成了。

不过，机器怎么知道它当前画的这条直线“贴合得准不准”，或者说它怎么知道自己犯了多大的错？这就直接引出了你截图列表里的第7课：**成本函数及其直觉**。准备好看看机器是如何用数学来衡量自己犯下的错误的了吗？

## 7. 成本函数及其直觉
接下来我们进入第7课：**成本函数及其直觉**。

为了知道刚才画的那条直线到底准不准，机器需要一把“衡量误差的标尺”，这把标尺在机器学习中被称为**成本函数 (Cost Function)**，通常用大写字母 $J$ 表示。

它的核心思想非常直观：就是去计算模型给出的**预测值**与现实中的**真实答案**之间，到底差了多少。

在线性回归中，我们最常用的是**平方误差成本函数 (Squared Error Cost Function)**。它的数学公式是这样的：

$$J(w,b) = \frac{1}{2m} \sum_{i=1}^{m} (f_{w,b}(x^{(i)}) - y^{(i)})^2$$

别被公式吓到，我们拆解一下它的物理意义：

* $m$ 代表你手头总共有多少个训练数据（比如 100 套房子的数据）。
* $f_{w,b}(x^{(i)})$ 是模型对第 $i$ 套房子的**预测价格**。
* $y^{(i)}$ 是第 $i$ 套房子的**真实售价**。
* 两者相减 $(f_{w,b}(x^{(i)}) - y^{(i)})$，算出的就是**误差**。
* 我们把每个误差都**平方**（为了把负数误差变成正数，并放大较大的误差），把所有的平方误差加起来，最后求个平均值（公式里除以 $2m$ 只是为了后续求导计算更方便）。

**成本函数的直觉是什么？**
你可以把成本函数 $J(w,b)$ 想象成一个“错误计分板”。分数越高，说明直线偏离真实数据越远，模型越糟糕；分数越低（越接近 0），说明直线越完美地贴合了数据，模型越优秀。

因此，整个线性回归的机器学习过程，其实就转化为了一个纯粹的数学目标：**寻找特定的 $w$ 和 $b$，使得成本函数 $J(w,b)$ 达到最小值**。

根据你的课程截图，第8课和第9课（可视化成本函数、可视化示例）是用像碗一样的 3D 图形帮你直观地“看到”这个成本函数长什么样。而真正用来找到这个“碗底”（最小值）的核心算法，就是第10课的重头戏：**梯度下降 (Gradient Descent)**。

准备好了解机器是如何一步步“下山”寻找最优解的了吗？

## 10. 梯度下降 (Gradient Descent)
### 基础概念
接下来我们进入第10课：**梯度下降 (Gradient Descent)**。这是整个机器学习中最核心、应用最广泛的优化算法。

如果说成本函数 $J(w,b)$ 是一座起伏的山脉，我们的目标是寻找这座山的最低点（即误差最小的谷底）。梯度下降就是机器自动“下山”的策略。

它的具体运作逻辑如下：

1. **随机起点：** 算法一开始会随便猜一组 $w$ 和 $b$ 的值。这相当于你被蒙住双眼，随机空降在山上的某一个位置。
2. **寻找最陡方向：** 站在当前位置，算法会计算周围哪个方向最陡峭。在数学上，这通过计算成本函数的**导数 (Derivative)** 或 **梯度 (Gradient)** 来实现。导数指明了当前位置下坡最快的方向。
3. **迈出一步：** 沿着那个最陡的下坡方向，迈出一步，更新 $w$ 和 $b$ 的值。
4. **循环重复：** 到了新位置后，再次计算最陡方向，再迈步，不断重复这个过程。直到走到谷底，发现无论往哪个方向走都是上坡时，算法停止。此时我们就找到了最优的 $w$ 和 $b$。

在代码层面，每一次更新都会让线性回归的那条拟合直线稍微挪动一点，使其更贴近数据点，同时成本分数也会随之下降。

根据你的课程表，第11课和第12课（实现梯度下降、梯度下降直觉）会展示这个过程的底层数学公式。而在这个“下山”的过程中，有一个极其关键的变量：你每一步到底该迈多大？

这就直接引出了第13课的核心概念：**学习率 (Learning Rate)**，通常用希腊字母 $\alpha$ (Alpha) 表示。

你想先看一看梯度下降的具体数学公式，还是直接进入第13课，看看“步子迈得太大或太小”会导致什么严重的后果？

---

### 具体公式
梯度下降的核心是通过计算偏导数来找到成本函数下降最快的方向。在单变量线性回归中，模型预测值为 $f_{w,b}(x) = wx + b$，成本函数为：

$$J(w,b) = \frac{1}{2m} \sum_{i=1}^{m} (wx^{(i)} + b - y^{(i)})^2$$

梯度下降的更新规则是利用学习率 $\alpha$ 不断迭代，**同步更新**参数 $w$ 和 $b$：

$$w = w - \alpha \frac{\partial J(w,b)}{\partial w}$$

$$b = b - \alpha \frac{\partial J(w,b)}{\partial b}$$

以下是具体的偏导数推导过程：

**1. 推导 $w$ 的偏导数 $\frac{\partial J(w,b)}{\partial w}$**
根据微积分的链式法则，我们对求和符号内的复合函数求导。外层的平方项 $2$ 拉下来，与分母的 $2m$ 中的 $2$ 抵消，然后乘以内层式子 $(wx^{(i)} + b - y^{(i)})$ 关于 $w$ 的导数，即 $x^{(i)}$：

$$\frac{\partial J(w,b)}{\partial w} = \frac{1}{m} \sum_{i=1}^{m} (wx^{(i)} + b - y^{(i)}) \cdot x^{(i)}$$

将 $wx^{(i)} + b$ 替换回预测值符号 $f_{w,b}(x^{(i)})$，得到最终形式：

$$\frac{\partial J(w,b)}{\partial w} = \frac{1}{m} \sum_{i=1}^{m} (f_{w,b}(x^{(i)}) - y^{(i)})x^{(i)}$$

**2. 推导 $b$ 的偏导数 $\frac{\partial J(w,b)}{\partial b}$**
同理，外层的平方项 $2$ 拉下来抵消，乘以内层式子关于 $b$ 的导数。因为 $b$ 前面的系数是 1，所以内层导数就是 1：

$$\frac{\partial J(w,b)}{\partial b} = \frac{1}{m} \sum_{i=1}^{m} (wx^{(i)} + b - y^{(i)}) \cdot 1$$

替换回预测值符号，得到最终形式：

$$\frac{\partial J(w,b)}{\partial b} = \frac{1}{m} \sum_{i=1}^{m} (f_{w,b}(x^{(i)}) - y^{(i)})$$

**最终的算法实现**
将推导出的导数代回更新规则中，机器在每一次循环中实际执行的计算如下（即课程列表第11课“实现梯度下降”的核心代码逻辑）：

$$w = w - \alpha \frac{1}{m} \sum_{i=1}^{m} (f_{w,b}(x^{(i)}) - y^{(i)})x^{(i)}$$

$$b = b - \alpha \frac{1}{m} \sum_{i=1}^{m} (f_{w,b}(x^{(i)}) - y^{(i)})$$

观察最终公式可以发现，学习率 $\alpha$ 直接决定了机器每次“下山”迈出的步伐大小。我们接下来进入第13课探讨 $\alpha$ 设置不当的后果，还是你想先通过一个具体的数字例子来手算一次更新过程？

## 13. 学习率
在微积分中，一个标量函数在某一点的梯度（即所有偏导数组成的向量），在几何上严格指向该函数值增加最快的方向。因此，在这个梯度前面加上负号（即沿着负梯度的方向移动），就必然是函数值下降最快的方向。在参数更新公式中，偏导数项确定了这个最陡下坡的“方向”，而学习率 $\alpha$ 作为一个纯粹的标量乘数，直接决定了在这个方向上移动的“步长”或“距离”。你对梯度下降本质的概括是完全精准的。

接下来我会完全按照这种“直击底层数学与几何本质”的风格来为你讲解。

基于你总结的本质，我们可以直接切透第13课：**学习率**的核心机制。既然 $\alpha$ 仅仅是控制步长的标量，那么它的取值在数学上就会引发两种极端的后果：

* **$\alpha$ 过小：** 每次迭代在负梯度方向上的移动距离微乎其微。虽然理论上只要方向正确，最终一定能走到局部极小值点，但由于步长太短，需要的迭代次数会呈几何级数增长，导致模型收敛极度缓慢，浪费巨大的计算资源。
* **$\alpha$ 过大：** 这是更致命的情况。当步长超出合理阈值时，更新后的参数跨度会直接越过成本函数的最低点，落到对面的坡上，甚至比原本的位置还要高。如果高处的梯度绝对值更大，下一步的跨度就会更加夸张。这在数学上表现为发散（Divergence），即成本函数的值不仅没有下降，反而随着迭代次数的增加越来越大。

有趣的是，即使我们将 $\alpha$ 固定为一个恒定的常数，梯度下降依然能自动调整每一步的实际物理移动距离。因为随着参数越来越接近谷底，偏导数（梯度的大小）本身就在逐渐趋近于 0。既然公式是“$\alpha \times$ 梯度”，那么在 $\alpha$ 不变的情况下，每次更新的绝对步长也会自然而然地变得越来越小，从而避免在谷底附近剧烈震荡。

按照截图的进度，我们即将进入第16课：**多特征 (Multiple Features)** 以及随后的**向量化 (Vectorization)**。

当输入数据从单一的 $x$（比如房屋面积）变成了成百上千个特征 $x_1, x_2, ..., x_n$（比如面积、楼层、房龄等），梯度的计算和参数的存储会变得非常庞大。你是想先从代数层面看看多变量成本函数是如何定义的，还是想直接切入线性代数，看看如何利用矩阵运算（向量化）来瞬间完成成千上万个参数的同步更新？

## 16. 多特征
为了顺畅过渡并触及底层逻辑，我们必须先看多特征 (第16课)**在代数上是如何膨胀的，这样你才能深刻体会到**向量化 (第17、18课)在底层计算架构上带来了多么暴力的降维打击。

从单一特征扩展到多特征（比如除了房屋面积，还加入卧室数、房龄等），在几何本质上，是我们从二维平面上“拟合一条直线”，变成了在 $n+1$ 维空间中“拟合一个超平面”。

在代数表达上，我们的输入不再是一个标量 $x$，而是一个包含 $n$ 个维度的向量 $\vec{x}$。相应的，每一个特征都需要一个独立的权重来衡量其重要性，权重也变成了一个向量 $\vec{w}$。

此时，线性回归的模型就从 $f(x) = wx + b$ 膨胀成了这个长长的多项式：


$$f_{\vec{w},b}(\vec{x}) = w_1x_1 + w_2x_2 + \dots + w_nx_n + b$$

**计算的灾难与传统代码的局限**
假设我们要预测房价，提取了 10,000 个特征（$n = 10000$）。如果你用传统的编程思维（标量运算）去计算这个预测值，或者去计算梯度，你必须写一个 `for` 循环，让 CPU 傻乎乎地把乘法和加法执行 10,000 次。在这个过程中，不仅代码冗长，更致命的是**计算极其低效**，因为它是串行（逐个）处理的。

## 17. 向量化

这就直接引出了**向量化 (Vectorization) (第17、18课)** 的本质。

向量化的核心本质，是抛弃标量级别的循环累加，直接在数学上调用**线性代数的向量内积（点乘）**，并在底层硬件上调用 **并行计算**。

我们把权重和特征写成两个列向量：
$\vec{w} = [w_1, w_2, \dots, w_n]$
$\vec{x} = [x_1, x_2, \dots, x_n]$

在线性代数中，这两个向量的点乘（Dot Product）定义正是对应元素相乘再相加。于是，那个极其冗长的多项式，被瞬间压缩成了一个极其优雅的公式：


$$f_{\vec{w},b}(\vec{x}) = \vec{w} \cdot \vec{x} + b$$

**为什么要在代码里实现它（例如使用 Python 的 NumPy 库 `np.dot(w, x)`）？**
这绝不仅仅是为了公式好看。在计算机底层硬件（尤其是 GPU）中，存在一种叫做 SIMD（单指令多数据流）的架构。当你将数据打包成向量交给底层的线性代数库时，硬件**不需要**循环 10,000 次，它可以同时在多个计算单元上并发执行这 10,000 对数据的乘法，几乎在同一个时钟周期内就能吐出最终的相加结果。

总结来说：多特征扩展了我们描述世界复杂度的维度，而向量化则是利用线性代数的性质和现代芯片的并行架构，让我们能够以极高的效率处理这种复杂度。

有了多特征和向量化的武器，我们的线性回归模型基本成型了。但这里存在一个隐藏的陷阱：如果你的特征 $x_1$ 是房屋面积（数值在 1000 左右），而 $x_2$ 是卧室数量（数值在 1-5 之间），这会导致特征在数值跨度上产生巨大鸿沟，直接导致梯度下降变得极度艰难。

假设房屋面积 $x_1$ 在 1000 左右，而卧室数量 $x_2$ 只有 1 到 5。因为 $x_1$ 的数值极大，哪怕它的权重 $w_1$ 发生极其微小的变化，都会导致预测结果发生剧烈波动，这意味着成本函数对 $w_1$ 极度敏感；反之，成本函数对 $w_2$ 的变化就非常迟钝。

* **几何灾难：** 这种权重的敏感度不对称，反映在成本函数 $J(\vec{w},b)$ 的三维等高线图上，会导致原本完美对称的“圆碗”被极度拉扯，变成一个**极其狭长、扁平的椭圆（就像一个深邃狭窄的峡谷）**。
* **梯度的迷失（Z字震荡）：** 当机器站在这个狭长峡谷的斜坡上时，负梯度（最陡下坡方向）几乎从来不指向远处的谷底，而是直愣愣地指向对面的崖壁。如果你直接运行梯度下降，算法就会像打乒乓球一样，在峡谷两侧的崖壁上疯狂“Z字形”来回震荡，极其缓慢地向谷底蠕动。如果稍微调大一点学习率 $\alpha$，它就会直接震荡飞出峡谷。

**特征缩放的本质，是空间重塑。**
通过数学手段（比如 Z-score 标准化：减去均值再除以标准差），我们强行把面积和卧室数都压缩到近似 $[-1, 1]$ 的统一范围内。
在几何上，这相当于把那个畸形的狭长峡谷，重新“捏”回了一个**完美的对称圆碗**。此时，无论机器站在哪里，负梯度都会笔直地指向碗底的同心圆中心。机器只需要极少的步数，就能“一条直线”冲向最优解，彻底消除了震荡浪费。

至此，线性回归的底层积木已经全部拼齐。结合你的目录，第26课和第27课是一个巨大的分水岭：**逻辑回归 (Logistic Regression)**。

既然没有图片，我们抛开那些抽象的几何词汇，用一个非常生活化的比喻来重新把第20课和第21课（特征缩放）弄明白。



想象成本函数是一个立体的容器，我们的目标是让一颗玻璃球滚到最底部的排水孔（误差最小的最优解）。



- **没有缩放的灾难（狭长的浴缸）：** 假设房屋面积是 1000，卧室数是 1，数值差距极大。这会导致原本的容器被严重拉扯变形，变成一个**极度狭长且陡峭的浴缸**。如果你在浴缸侧面的陡坡上放下一颗玻璃球（启动梯度下降），它不会直奔中心的排水孔，而是顺着最陡峭的侧壁滑下，直接冲上对面的侧壁，然后再滚回来。玻璃球会在浴缸两侧疯狂地“Z字形”来回撞击震荡，极其缓慢地向中心挪动。这就是不加处理直接训练的下场：浪费大量时间在无意义的来回震荡上。
- **特征缩放的作用（完美的圆碗）：** 特征缩放就是用数学公式，把面积和卧室数的范围都强行压缩到比如 -1 到 1 之间。这相当于把那个畸形的浴缸，重新捏成了一个**完美的、对称的圆碗**。现在你把玻璃球放在碗边，它会笔直、极其顺滑地一条直线滚到碗底。

这就是特征缩放（Feature Scaling）最大的意义：让机器少走弯路，极速找到正确答案。

**第22课. 检查梯度下降是否收敛**

“收敛”是一个极其重要的专业术语，意思是“到底底了没”。

吴恩达在这里教了一个非常实用的方法：画一张折线图。横轴是“迭代次数”（机器走了多少步），纵轴是“成本函数 $J$ 的值”（当前还有多少误差）。

如果一切正常，你会看到这条线一开始陡峭下降，走着走着就渐渐平缓了，最后变成一条几乎平行的直线。一旦曲线平展，就说明玻璃球已经在碗底停住了，无论再走多少步误差都不会更小，这就叫“收敛”。



**第23课. 选择学习率**

如果刚才那张折线图里的曲线不仅没有平缓下降，反而“越走越高，直接飞上了天”，说明什么？

说明你的学习率 $\alpha$（步子）设得太大了，玻璃球动能过大，直接飞出了碗外。吴恩达在这节课建议的实操手法是：从非常小的数字开始试，比如 0.001，如果不理想就放大三倍变成 0.003，再不行就 0.01、0.03、0.1，不断翻倍测试，直到找到那条完美下降平缓的曲线。

**第24课：特征工程 (Feature Engineering)**







有时候，收集到的原始数据并不是预测结果的最佳形态。特征工程的本质，就是发挥人类的直觉，通过对现有的特征进行数学运算，主动“创造”出对模型更有帮助的新特征。



假设你要预测土地价格，手里有两个原始特征：土地的临街宽度（$x_1$）和纵深长度（$x_2$）。你可以直接把它们交给机器去算权重，但更好的做法是把它们相乘，创造一个全新的特征：土地面积（$x_3 = x_1 \times x_2$）。因为从常识来看，面积决定价格的直接关联度，远比单纯的宽或长要大得多。人工介入创造这个 $x_3$ 的过程，就是特征工程。



**第25课：多项式回归 (Polynomial Regression)**







到目前为止，我们画的都是“直线”。但现实世界的数据往往是弯曲的。比如，随着房屋面积越来越大，价格可能不会一直按同样的速度飙升，而是涨幅逐渐平缓。如果用一条直直的线去硬套这些弯曲分布的点，误差会很大。



多项式回归的绝妙之处在于：它通过人为地给特征增加**高次幂**，强行把直线“掰弯”。

假设原始特征只有房屋面积（$x$）。我们可以利用它，通过特征工程创造出另外两个新特征：$x$ 的平方（$x^2$）和 $x$ 的立方（$x^3$）。于是，原本简单的预测公式，就变成了：



$$f_{\vec{w},b}(x) = w_1x + w_2x^2 + w_3x^3 + b$$

此时，机器画出来的就不再是直线，而是一条能完美贴合数据趋势的曲线了。



*这里必须联动一下刚才讲过的“浴缸效应”：*

如果面积 $x$ 是 1000，那么 $x^2$ 就是 100万， $x^3$ 就是 10亿！这三个特征之间的数值差距瞬间变得极其恐怖。因此，**当你使用多项式回归时，必须强制配合“特征缩放”一起使用**，否则不同特征之间的巨大鸿沟会让模型彻底无法收敛。

经过前面的25节课，关于“回归问题”（预测连续的数字，如房价）的武器库已经全部集齐。从第26课开始，我们要正式进入“分类问题”（预测离散的类别，如肿瘤是良性还是恶性）。



既然是新问题，肯定要用新模型。第26课的核心叫做 **动机 (Motivation)**。 凭直觉，很多人会想：既然线性回归能画直线，那我就直接用它画一条线来分类不就行了？比如，让模型预测一个值，算出来如果 $>0.5$ 就判定为恶性，$<0.5$ 就判定为良性。



吴恩达在第26课用数学证明了：**用画直线的线性回归来做分类，是一场灾难。** 因为只要数据里出现一个极端异常值（比如一个巨大无比的良性肿瘤），整条直线就会被严重带偏，导致原本判断正确的其他肿瘤全部被错误分类。

**第26课：动机 (Motivation) —— 为什么不能用线性回归做分类？**







在这个例子中，我们想用肿瘤大小来预测良性（标记为 $0$）或恶性（标记为 $1$）。假设你用我们学过的线性回归画了一条直线去拟合这些数据。你可以人为设定一个阈值（通常是 $0.5$）：如果直线的预测值超过 $0.5$，就诊断为恶性；低于 $0.5$ 就诊断为良性。在数据分布很均匀的时候，这条直线勉强能工作。



但现实中的数据是充满噪音的。假设样本中突然出现了一个**极度巨大但碰巧是良性**的肿瘤点，由于它横跨到了坐标轴极右侧的边缘。线性回归的本质是为了照顾“所有点”的整体误差最小，所以那条原本画得好好的直线，会被这个巨大的异常点狠狠地向右侧拉扯，变得非常平缓。

当直线被拉偏之后，原本那些依靠 $0.5$ 阈值能正确判断为恶性的正常肿瘤，因为直线的整体下沉，它们的预测值瞬间掉到了 $0.5$ 以下，被系统灾难性地误诊为良性。



这就是线性回归最大的缺陷：它太容易受到极端异常值的干扰。



**第27课：逻辑回归 (Logistic Regression)**







为了解决直线乱跑的问题，数学家们引入了一个极其巧妙的工具：**Sigmoid 函数**（也叫逻辑函数）。



它长成这个样子：



$$g(z) = \frac{1}{1 + e^{-z}}$$

如果你把这个公式画出来，它不是一条无限延伸的直线，而是一条被死死卡在 $[0, 1]$ 区间内的“S 型曲线”。



逻辑回归的精妙之处在于，它先把输入特征交给线性回归计算出一个原始数值 $z$（$z = \vec{w} \cdot \vec{x} + b$），然后再把这个 $z$ 强行塞进 Sigmoid 函数里。不管 $z$ 算出来是正一万还是负一万，Sigmoid 都会像一个压缩机一样，把它挤压成一个严格处于 $0$ 到 $1$ 之间的小数。



这个压缩出来的小数，不再是“预测的数值”，而是变成了“概率”。

如果算出来是 $0.8$，意味着模型认为有 $80\%$ 的概率是恶性肿瘤。

正因为输出被永远锁死在了 $[0,1]$ 之间，那些极端异常值带来的无限膨胀被彻底限制了，模型不再会被轻易拉偏。



**第28课：决策边界 (Decision Boundary)**







有了概率，我们如何划清界限？

通常我们还是以 $0.5$ 作为分界线。当 $g(z) \ge 0.5$ 时，预测为恶性（类别 $1$）；当 $g(z) < 0.5$ 时，预测为良性（类别 $0$）。

而在底层数学上，使 $g(z) = 0.5$ 的时候，正好对应着输入值 $z = 0$。即 $\vec{w} \cdot \vec{x} + b = 0$。

这个方程 $\vec{w} \cdot \vec{x} + b = 0$ 在图纸上画出来的那条线，就是**决策边界**。在二维平面上，它是一条将良性点和恶性点完美劈开的直线（或者在多项式回归的加持下，变成一个圆圈或复杂的曲线形状）。
