## 6.S081 怎么学

结论很明确：

**学，但只学核心，不要把它刷成第二主线。**

做法是：

* 先听课，建立 OS 整体框架
* 重点吸收：进程、线程、锁、虚拟内存、IO、系统调用
* lab 先做最有价值的，不要全部一口气刷完

你第一课的笔记方向是对的：user/kernel mode、system call、fork/exec/wait、redirect，这些已经抓住骨架了。现在要做的是把术语再标准化一点，把理解落到工程语言上。

* tensor

# C++ 现在怎么学

你前面问的函数模板、智能指针、STL 这些，都属于“必须掌握，但学到够用就停”的部分，不需要啃成模板元编程专家。

推荐顺序：

1. 指针 / 引用 / const / static
2. 类 / 对象 / 构造 / 析构
3. 拷贝控制 / move
4. 智能指针
5. STL / 模板基础
6. lambda / function / bind
7. 并发
8. 网络编程
9. 工程化 / 调试 / 性能意识
