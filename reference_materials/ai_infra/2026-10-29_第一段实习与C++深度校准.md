## 3. 结论：岗位是三层，不是两个互斥按钮

```text
主投层
C++后台 / Linux / 系统 / 存储 / 网络

并行层
大模型平台后端 / 推理服务外围 / AI云原生基础设施

少量冲刺层
核心推理引擎 / CUDA / kernel / GPU profiling
```

主投层最贴合当前证据。并行层能够让系统能力更早接到AI工作负载，不必等待完整CUDA路线。冲刺层用于观察门槛和争取培养机会，但不能把尚未完成的能力写成已会。

岗位价值按实际工作判断：是否写代码、处理Linux/网络/存储/调度、做测试与性能定位、接受review和真实协作。标题带“AI Infra”不自动优于高质量系统岗；反过来，C++系统岗也不等于放弃AI Infra。

## 4. C++ 深度怎样服务长期目标

| 深度 | 当前要求 |
|---|---|
| 正确使用 | 所有权、生命周期、容器失效、同步、I/O、错误与测试必须扎实 |
| 常见实现模型 | string/vector/map/unordered_map/list、虚调用、allocator第一层要能从需求解释结构与代价 |
| 代表题手写 | StringLike、LRU、RingBuffer、BlockingQueue/ThreadPool足够形成第一批证据 |
| 深水区 | 完整STL源码、ABI、多继承布局、生产allocator、lock-free/RCU、C++26按岗位和瓶颈后置 |

这条边界既避免“AI Infra只学PyTorch、不懂系统”，也避免“先学完所有C++底层，才能开始AI”。
